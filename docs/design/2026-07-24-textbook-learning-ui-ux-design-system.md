# 教材驱动学习与测评：UI/UE 设计系统（Gate 3）

状态：已确认

## 1. 背景

产品服务小学至初中学生及家长，既需要轻松易懂的学习入口，也要在试卷与诊断环节保持学校考试的严肃、清晰和可信。

## 2. 目标

采用“明亮、安静、任务优先”的学习工具风格：学生不必阅读大段说明即可开始，家长可以在结果页快速检查评分依据。

## 3. 方案

### 3.1 视觉方向与令牌

| 项目 | 规则 |
| --- | --- |
| 产品类别 | 家庭学习应用，学生高频使用，家长间歇复核。 |
| 视觉方向 | 清爽的学习工具，不使用营销式英雄区、炫光背景或大面积渐变。保留现有学科色，但降低装饰性动态背景。 |
| 色彩 | 墨色 `#1F2937` 为正文；纸白 `#FFFFFF` 为考试面；学科色：英语青蓝、数学靛蓝、科学青绿、语文暖红。正确 `#16803C`、警示 `#B45309`、错误 `#B91C1C`。颜色不单独表达状态。 |
| 字体 | 系统中文无衬线，正文 16px、题干 18px、考试标题 20px、页面标题 24px；不使用随视口缩放和负字距。 |
| 间距 | 4/8/12/16/24/32px；卡片圆角最多 8px，考试纸面 2px。 |
| 阴影 | 仅浮层和可点击卡片使用轻阴影；考试区使用细边框，不制造漂浮感。 |
| 图标 | 复用 Lucide；听力 `Headphones`、视频 `Play`、练习 `PencilLine`、测试 `FileText`、下载 `Download`、复核 `MessageSquareWarning`。图标按钮必须有 tooltip 和 aria-label。 |

### 3.2 页面布局

| 页面 | 桌面 | 移动端 |
| --- | --- | --- |
| 学习中心 | 左侧教材/章节栏，右侧四行动网格与最近任务。 | 教材和章节为顶部选择器；四行动为两列固定高度磁贴。 |
| 学习包 | 主阅读区 + 右侧章节上下文。 | 单列，章节上下文收进抽屉。 |
| 命题配置 | 600px 宽分步表单，右侧蓝图预览。 | 单列分步，底部固定“下一步/生成”。 |
| 网页考试 | 72px 题号栏 + 最大 800px 纸面 + 交卷栏。 | 顶部进度、横向可滚动题号、单列纸面，底部固定保存/交卷。 |
| 诊断 | 总分摘要 + 逐题评分表。 | 摘要紧凑；每题展开评分点与复核操作。 |

### 3.3 组件与交互规则

| 组件 | 行为 |
| --- | --- |
| 行动磁贴 | 整块可点击，包含图标、动作名、章节名和预计时长；不使用纯装饰插图。 |
| 难度分段控件 | 基础/标准/挑战三段，默认标准；点击即更新蓝图预览，不立即生成。 |
| 试卷题目 | 选择题使用单选控件；填空题有稳定输入高度；解答题有可扩展答题区和保存状态。 |
| 音频控制 | 仅用播放、暂停、重播图标；显示剩余播放次数与当前状态，不能以文本按钮模拟播放器。 |
| 评分点表 | 每一行显示“要求、学生证据、得分/分值、原因”；低置信度使用图标+文字。 |
| 复核 | 二级按钮打开侧栏，填写原因后提交；“改为正确/错误”仅作为带确认的家长操作。 |
| 下载 | 下载图标配文件名和 A4 标签；试卷与答案卷分开操作。 |

### 3.4 可访问性、动效与视觉验收

- 文字/背景至少 WCAG AA 对比度；焦点状态 2px 可见描边；所有操作可键盘完成。
- 触控目标至少 44x44px；长教材标题、题干、评分证据自然换行，不截断关键内容。
- 只在进度、音频播放与成功状态使用 150-200ms 过渡，遵从 `prefers-reduced-motion`。
- 实现后提供 1440px、768px、390px 截图；检查考试纸面、底部操作条、长题干、数学公式和复核侧栏无重叠。

## 4. 风险

当前 `Layout` 使用高饱和渐变和 `FloatingDots`，会降低考试页面的纸面可读性。考试、PDF 预览与诊断详情必须使用隔离的浅色考试布局，不能继承装饰性背景。

## 5. 回滚

新样式只作用于学习中心和新考试路由。现有看板、书架、拍题和 AI 课堂继续使用当前样式令牌。

## 6. FAQ

### 为什么不把所有学习入口放进卡片？

卡片只用于可重复选择的四类学习行动。页面区块、考试纸面和诊断内容保持无框结构，避免嵌套卡片影响扫描效率。
