# 母卷原创测试：视觉与交互规范

## 1. 背景

Gate 3待确认。依据[PRD](../plans/2026-10-16-source-paper-practice-prd.md)。面向小学生与家长的家庭学习工具，采用现有学习资料/小助手的页面语言，不建立新主题。

2026-10-16已核对当前`tailwind.config.js`及`LearningAssistant.tsx`：实际为豆沙绿底、深色文字，蓝/紫局部强调。旧设计文档中的深色背景、已取消视频或听力次数限制不能沿用到本轮。

## 2. 目标

进入页面即能识别“选母卷 → 核对结构 → 生成测试”；信息清晰、正文易读、按钮层级稳定，390px设备不依赖横向数据表才能完成操作。

## 3. 方案

### 3.1 设计token与布局

| 项 | 复用约束 |
| --- | --- |
| 背景/面板 | `cyber.bg #E8EFE3`、`bg2 #DDE5D7`、`surface #F0F4EC`；延续现有面板透明度与边框 |
| 文字/边框 | `text #2A3026`、`muted #5C6655`、`border #C6D1BD`；不可把浅学科色用作小号正文 |
| 强调/语义 | `neon.blue #1F6FB2`、`purple #6D28D9`用于现有选中/主按钮；`green #15803D`成功；`amber #B45309`需处理；`pink #B91C1C`错误 |
| 字体 | 现有`Inter, PingFang SC, Microsoft YaHei, system-ui`；无新网络字体。A4继续既有随镜像字体方案 |
| 字号 | 页面标题20px/700；分区16px/600；表单和正文16px；摘要14px，辅助12px；正文行高至少1.5 |
| 间距 | 4/8/12/16/24/32px；页面分区24px、表单16px、紧邻标签8px |
| 圆角/阴影 | 控件12px、面板16px；复用`shadow-card`/`glow-sm`，不叠加多层发光 |
| 容器 | 沿用`max-w-6xl`；页边距手机16px、平板24px、桌面按现有壳；表单主区可读宽度优先 |
| 图标 | 现有lucide线性图标16～24px；“试卷出题”使用可辨识试卷图标与文字，不用图标替代标签 |
| 动效 | 遵守现有过渡；新增过渡120～200ms，减少动态设置下移除装饰动画；无庆祝或无限脉冲装饰 |

token是复用基线，不是未经验证的对比度承诺。实际透明叠加、焦点边框和正文必须实测WCAG AA：正文4.5:1、大字及必要控件边界3:1。

### 3.2 页面构成与示意

```text
大宝的学习小助手                         [沿用现有欢迎栏]
[教材章节学习] [错题讲解与测验] [模拟考试]
[母卷出题 | 奥数模拟]                     [模拟考试内的模式选择]

从母卷生成原创测试
当前学生：大宝 · 四年级
母卷：[广州四年级英语期末测试（仅笔试版）       v]
源卷：四年级 · 英语 · 仅笔试                [分析母卷]

核对出题结构
知识点：词汇运用、句意理解、阅读信息提取
分区           母卷子题数    本次子题数       材料说明
选择题              6          [6]         独立小题
选词填空            4          [4]         1组语境材料
阅读理解           10         [10]         2组阅读材料
合计               20          20
按当前四年级能力生成原创题，不复现母卷原题。
                                   [确认并生成原创测试]
```

示意为合成数据，不代表已分析用户母卷。桌面结构区为主内容、确认摘要为右侧窄栏；若内容量少可用单列，不能为凑两列增加空卡片。

### 3.3 组件与交互

- 同级圆角tab维持三个及原顺序，仅将“奥数模拟考试”更名为“模拟考试”。选中态含文字、底色、边框和`aria-selected`；手机需要时横向滚动至选中项。
- 模拟考试面板顶部增加轻量分段选择“母卷出题 / 奥数模拟”，默认母卷出题。可采用带明确组标签的原生单选语义及方向键操作，触达区域至少44px；不做第四个同级tab或新的全局菜单。模式切换与生成锁定一致。
- 母卷选择复用现有表单控件；选中后在下方完整换行显示长标题、学科、年级及范围，避免原生select截断关键信息。无封面大图和营销区域。
- 结构行优先展现题型和数量，知识点在独立摘要区域；可折叠题组说明但不隐藏材料缺失或范围警告。不显示模型置信度假数值。
- 数量字段始终带“本次子题数”标签；使用数字键盘提示但不依赖HTML数字输入自动校验。移动端每分区一块轻量行卡，母卷数/本次数并列。
- 单个阶段一个主按钮：选卷时“分析母卷”，结构确认时“确认并生成原创测试”，成功时“开始作答”。次级按钮用边框；无数据时主按钮旁说明原因。
- 危险操作仅在既有生成资料删除流程出现，沿用二次确认；本页不新增“删除母卷”按钮。
- 提示条采用图标+明确文案，警告不只依赖颜色；分析失败与生成失败分开。生成失败不将整个试卷卡渲染为可作答。
- 下载按钮区分“A4试卷”和“答案与解析”，加载/失败仅作用于对应文件，不干扰已存答案。

### 3.4 响应式、无障碍与验收截图

| 视口 | 行为与必验点 |
| --- | --- |
| 390×844 | 单列；tab仅区域内横滚，正文无横滚；每行题量输入可触达；主按钮满宽；长标题换行；进度窗口不超屏 |
| 768×1024 | 来源/年级可两列，结构仍优先可读；不强行固定右栏，按钮不遮内容 |
| 1440×900 | 主区+窄摘要区可并列，宽度不超过既有容器；表格列对齐且无巨量留白 |

所有按钮、输入、tab触达区域至少44×44px；键盘焦点有2px可见环；Tab顺序与视觉一致，tab支持方向键及Home/End，且不在未选tab面板聚焦。错误通过标签/描述关联到输入。

实现后每视口至少保存：选卷、结构确认（含长标题）、材料缺失、生成中、已完成回顾截图；另保存键盘流、页内锁定及5分钟解锁的检查记录。未实施前不宣称已通过浏览器QA。

### 3.5 避免的设计

不做独立深色工作台；不新增渐变大背景或超大标题；不把每个知识点堆成彩色卡片；不显示虚假百分比/完成时间承诺；不使用成绩仪表盘或正确率色块。

## 4. 风险

- 透明面板可能降低对比度，必须在实际背景上验证。
- 三个同级tab在手机按实际宽度横滚，选中项必须可见；内部两个模式选择不挤占同级tab，也不能挤成不可点击的小字。
- 复杂题组可能拉长页面，允许纵向阅读和轻量折叠，不可通过隐藏警告压缩页面。
