# 性能优化页面状态契约

状态：Gate 3 已确认

## 1. 背景

统一任务调度改变了 OCR、图书和课件的可见状态。状态不完整会导致用户重复提交、误删任务或无法恢复失败。

## 2. 目标

为每个任务类型定义可测试的正常、排队、处理、部分成功、失败、重试和不可用状态。

## 3. 方案

| 状态 | 图书 | OCR | 课件 | 用户可执行操作 |
| --- | --- | --- | --- | --- |
| 初始 | 选择文件 | 选择图片 | 选择章节 | 提交 |
| 上传中 | 字节进度 | 图片压缩/提交 | 不适用 | 取消尚未提交的本地操作 |
| 排队中 | 显示队列状态和已等待时间 | 同左 | 同左 | 查看状态；不重复提交 |
| 运行中 | 文本提取、转图、模型、保存等阶段名和已耗时 | OCR 或结构化阶段名和已耗时 | 核心生成、核心保存或扩展生成阶段名和已耗时 | 离开页面后任务继续；返回可查看状态 |
| 部分成功 | 元数据可编辑，全文处理中 | OCR 文本可编辑，结构化未完成 | 核心课件可打开，扩展讲解生成中或失败 | 仅重试未完成阶段 |
| 可用 | 图书可读且状态完成 | 结果可保存/查看 | 核心课件已保存且可打开；扩展完成后补全讲解 | 正常后续操作 |
| 失败 | 保留文件和元数据 | 保留图片和已完成文本 | 保留已生成内容 | 重试、查看可读错误 |
| 服务不可用 | 标明服务暂不可用 | 同左 | 同左 | 不创建重复任务 |

课件核心内容固定为导入、3 个关键知识节和小结，每节正文 120-180 个中文字符。扩展任务只补充详细讲解、例子和讲稿；它的失败不得回退或隐藏已保存的核心内容。

### LiveTutor 状态

| 状态 | UI 反馈 | 行为 |
| --- | --- | --- |
| 连接中 | 可见连接状态 | 不展示“倾听中”假状态 |
| 倾听中 | 麦克风激活状态 | 上行 PCM 流正常发送 |
| 回应中 | 音频播放状态和转写 | 可被用户新发言中断 |
| 重连中 | 提示正在恢复会话 | 不重放旧音频 |
| 失败 | 可读错误和重新连接按钮 | 关闭本地音频资源 |

## 4. 风险

- “处理中”无法说明具体阻塞点，必须至少携带阶段与已耗时。
- 取消已发送给模型的任务可能无法撤回外部成本，因此 MVP 不承诺取消远端已运行请求。

## 5. 回滚

旧任务缺少新状态字段时映射为“处理中”；不可因状态迁移导致书架或错题列表无法加载。

## 6. FAQ

### 任务是否会因为关闭页面丢失？

任务状态持久化后，用户返回页面应能够恢复查看；实现阶段需以服务端任务记录为准，而非前端内存状态。
