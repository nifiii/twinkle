# 母卷原创测试：页面状态

## 1. 背景

Gate 3待确认。依据[PRD](../plans/2026-10-16-source-paper-practice-prd.md)和[用户流程](2026-10-16-source-paper-practice-ui-flow.md)。状态ID用于验收和前端实现；不是API枚举。

## 2. 目标

资料缺失、识别不确定、生成中和已完成学习均有可验证展示；处理失败不显示成功，刷新不触发重复创建。

## 3. 方案

| 状态ID | 触发条件 | 展示/可操作项 | 禁止行为 |
| --- | --- | --- | --- |
| SP-S01 读取中 | 进入“模拟考试→母卷出题”读取候选与学生信息 | 状态文本“正在读取试卷资料”；保留页面壳与模式切换 | 空列表闪烁、自动分析默认第一项 |
| SP-S02 可选择 | 候选可用，尚未分析 | 母卷选择、学生年级、范围说明；可点击分析 | 显示章节、提前创建测试 |
| SP-S03 无母卷 | 无已归档试卷 | “暂无可用母卷，请在学习资料中归档试卷”；入口到资料页 | 诱导补教材目录、混入普通教材 |
| SP-S04 正文未就绪 | 未解析、解析失败、文件/正文不存在 | 具体状态与回资料页操作；可选其他母卷 | 只靠标签声称可用、发送空正文分析 |
| SP-S05 年级未确认 | 档案年级无有效依据 | 显示当前学生，提示先确认档案；可回既有档案入口 | 把兜底一年级或母卷年级作为目标 |
| SP-S06 分析中 | 已主动发起分析 | 标题、分析阶段、耗时；重复分析禁用 | 用倒计时伪装真实进度 |
| SP-S07 等待结构确认 | 全部结构/材料可核验 | 分区、题型、题组数、母卷/本次子题数、知识点；可调整并生成 | 未确认就生成、默默把题数降为10 |
| SP-S08 材料不足 | 缺页、缺图片、缺听力原文或阅读材料 | 列出具体分区/缺项与资料处理入口；可换卷 | 以警告但照常整卷生成、自动填补源材料 |
| SP-S09 结构不确定 | 题数/题型无法可靠识别或暂不支持 | 列出不确定项；重新分析或处理资料 | 要求学生猜题数并据此宣称识别成功 |
| SP-S10 配置无效 | 数量非正整数或已公开边界不支持 | 行内错误、顶部错误摘要，焦点到首个错误；保留输入 | 自动截断、静默改数、触发模型生成 |
| SP-S11 年级不适配 | 来源知识点无法在学生年级合理生成 | 源卷/目标年级及冲突知识点，提示换卷或处理范围 | 自动提高学生年级、补外部教材 |
| SP-S12 生成中/锁定 | 创建已受理且未到5分钟、无终态 | 已确认配置、真实阶段/耗时；焦点限于进度区域 | 改母卷/学生、重复提交、假完成百分比 |
| SP-S13 超过锁定阈值 | 等待达到5分钟仍无终态 | 解除页内锁定，“后台仍可能继续”；查看原任务 | 等同取消/失败、开放同一意图重复提交 |
| SP-S14 结果未知 | 断网、请求超时、刷新后尚不能核验受理 | “正在确认原任务状态”；受控查询，恢复同一请求 | 新建请求当作查询、无任务ID就假失败 |
| SP-S15 生成失败 | 服务端明确终态失败、整卷校验未过 | 易理解原因、原配置、显式重试；保留失败任务状态供追踪 | 展示可作答半成品、自动无限重试 |
| SP-S16 生成成功 | 完整卷已保存并关联任务 | 标题、总题量、开始作答/智慧课堂 | 标记学习已完成、展示评分 |
| SP-S17 学习中 | 打开试卷或保存草稿、未提交 | 题组材料与作答控件、继续学习 | 因阅读或播放即标为完成 |
| SP-S18 已完成 | 已成功提交，包括刷新/再次进入 | “已完成”“查看作答”；逐题题目、学生答案、参考答案、解析；需巩固 | “继续学习”、不可用、得分/对错/系统批改 |
| SP-S19 来源变化 | 换母卷/学生/出题模式、原资料版本变化/被删除 | 旧分析及未提交配置失效；新对象需重新核验；已生成试卷依快照读取 | 旧响应覆盖新选项、不同模式混用来源、已生成卷随资料变化被重写 |
| SP-S20 不可访问 | 来源不存在或当前档案不可访问 | 通用不可用提示、返回列表 | 声称ownerId是安全隔离、泄漏其他档案详情 |
| SP-S21 查询错误 | 列表/详情查询失败 | 错误提示与仅重试查询按钮；保留可识别选择 | 查询重试触发生成、错误当空列表 |
| SP-S22 下载异常 | PDF准备/下载失败 | 对应文件按钮显示忙碌/失败，可重试下载 | 重建测试、清空答案或错误下载母卷 |

### 3.1 状态转换约束

- SP-S06的分析结果只能进入当前模式、当前学生、当前来源及当前版本的SP-S07/08/09/11；过期响应丢弃。以上状态约束母卷模式，奥数模式沿用其已有状态；入口合并不改变奥数业务规则。
- SP-S07合法提交进入SP-S12；数量错误进入SP-S10，来源失效进入SP-S19。缺原卷答案本身不会进入SP-S08。
- SP-S12可转SP-S13/14/15/16；SP-S13/14经核验仍可转SP-S15/16。网络错误不是业务失败终态。
- 未确认范围/结构不开放部分成功整卷：部分分析结果仅作缺项说明；部分生成结果对学习入口不可见。
- SP-S16与SP-S18分开：生成成功与学习完成是两个事件，列表与详情以同一任务/提交事实呈现。
- 来源删除后，既有完整试卷和已提交答案按现有快照/删除契约访问；不得回读母卷是否存在来判断学习完成。

### 3.2 可用性与通知

状态变更使用`role=status`或礼貌播报；缺项和提交错误使用`role=alert`，避免每秒播报计时。进度窗口接收焦点，Tab/Shift+Tab按可聚焦元素循环；没有交互项时保留可聚焦状态容器，不使焦点落入被锁背景。终态恢复到成功区或首个错误。

仅显示用户所需信息，不展示SQL、正文原文、内部路径、模型原始错误。后台审计记录的最小字段及保留期限归Gate 4。
