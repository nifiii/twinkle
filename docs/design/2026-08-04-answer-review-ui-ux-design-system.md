# 作答回顾：UI/UX 设计契约（Gate 3）

## 1. 背景

作答回顾属于学生重复使用的学习工具，应沿用学习资料与智慧课堂的克制、清晰页面语言。

## 2. 目标

让对照阅读比操作本身更突出，避免任何考试评分暗示。

## 3. 方案

- 使用现有白底、细边框、深色正文与学科色点缀；不新增独立主题、渐变或奖惩色。
- 每题为一个连续阅读区：题号与题型、题目、我的答案、参考答案、解析、需巩固操作，顺序固定。
- “需巩固”使用书签/旗帜图标加文本；标记后显示“已加入需巩固”，可再次点击取消。不得用红色叉号、对勾或“错误”文案。
- 页面标题使用“作答回顾”，历史列表使用“已完成作答”；不使用“成绩”“批改”“得分”“正确率”。
- 390px 单列；768px 以上可让“我的答案/参考答案”并排，但解析始终整行；1440px 限制阅读宽度，避免横向扫视。
- 所有开关和返回操作可通过键盘访问，焦点清晰；状态同时包含图标、文本和 `aria-pressed`。

## 4. 风险

- 不能只隐藏分数而仍保留正确/错误色彩、图标或 DOM 标签；视觉和辅助技术语义均须删除。
