# 1. 背景

验收覆盖文字母卷回归和新增多模态能力。

# 2. 目标

用确定性依赖替身验证契约，不依赖生产模型。

# 3. 方案

1. 安全路径：数据卷内 PDF 可读取，数据卷外路径被拒绝。
2. Vision：页面证据可解析；低置信度/缺失项阻断。
3. 多选：生成、校验、checkbox 作答、提交和回顾保留数组答案。
4. 听力：有原文调用现有原创听力生成依赖；无原文明确失败。
5. 图形：简单图形资源可在网页和 PDF 中输出；原图不进入新卷。
6. 旧文字蓝图、单选、填空、解答题回归通过。
7. 后端测试、前端构建和 390/768/1440 三视口冒烟通过。

# 4. 风险

真实ARK/Vision/TTS调用只在用户另行授权后验证；本轮只做本地确定性验收。
