# 1. 背景

验收覆盖文字母卷回归和新增多模态能力。

# 2. 目标

用确定性依赖替身验证契约，不依赖生产模型。

# 3. 方案

1. 安全路径：数据卷内 PDF 可读取，数据卷外路径被拒绝。
2. Vision：页面证据可解析；低置信度/缺失项阻断。
3. 多选：生成、校验、checkbox 作答、提交和回顾保留数组答案。
4. 听力：有原文调用现有原创听力生成依赖；无原文明确失败。
5. 图形：简单图形资源可在网页和 PDF 中输出；原图不进入新卷。
6. 旧文字蓝图、单选、填空、解答题回归通过。
7. 后端测试、前端构建和 390/768/1440 三视口冒烟通过。
8. 有完整视觉证据的看图填空/看图写话可分析；学生画图、缺失原图继续失败。看图题缺原创配图或包含外链/脚本时不保存半卷。
9. 原创 SVG 在作答页、预览、已提交作答快照及两版 PDF 均保留；刷新回顾不丢图。
10. 本次用户明确要求生产实际验收：在正式母卷入口重新分析并按默认题量生成，打开真实新卷检查题目、选项和配图。测试替身通过不等于该项通过。
11. 生成请求只含当前分区结构，不注入全母卷视觉证据；保留当前分区的图片与材料要求。
12. 不同短文、配图、选项或听力原文中的相同作答指令可以保存；题型、题干及全部作答材料均相同的真重复题拒绝，且不保存半卷。

# 4. 风险

真实ARK/Vision/TTS调用须有用户授权。本轮用户已要求生产实际生成所选母卷的新卷；该笔试母卷不含听力，不能据此宣称真实TTS或所有母卷都已通过。
