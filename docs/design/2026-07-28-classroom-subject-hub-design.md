# 智慧课堂学科任务首页设计

## 背景

智慧课堂已是学习任务的统一入口，但原首页使用多个下拉筛选器，且视觉层级与学习资料不一致。家庭学习场景需要让学生先按学科快速定位待学习内容。

## 目标

- 默认展示语文的待学习任务。
- 使用学科标签切换，不使用学科下拉筛选器。
- 将同一学科的任务按学习目的分组，便于学生直接继续学习。
- 复用学习资料的标题信息条、标签栏、字体层级、边框、按钮和状态反馈风格。

## 页面结构

1. 页面标题：智慧课堂与当前学生名称，右侧保留刷新图标按钮。
2. 学科导航：语文、数学、英语、科学优先，其余已上传教材学科追加；键盘可通过 Tab 与 Enter/Space 切换。
3. 待学习分组：课件与随堂测验、错题讲解与测验、视频学习、试卷、其他训练。分组内为扁平任务行，不嵌套卡片。
4. 辅助状态：加载、读取错误、当前学科无待学习任务、加载更多。

## 数据与交互

- 复用 `GET /api/learning-tasks`，初次与学科切换时带 `subject=<选中学科>`、`status=ready`。
- 首页仅显示待学习任务；生成失败或历史状态不改变既有详情访问能力，但不混入学生的待学习清单。
- 点击任务进入 `#tutor/task/:id`，不改变详情路由与内容渲染契约。

## 视觉规则

- 使用 `cyber-text`、`cyber-muted`、`cyber-border`、`neon-blue` 既有语义 token，避免单独配色。
- 顶部使用学习资料同款半透明信息条、12px 图标方块和蓝紫渐变标题；分组标题为 `text-base`，任务信息为 `text-sm`；不使用视口缩放字体。
- 学科标签使用学习资料同款圆角标签栏，选中态使用蓝紫渐变底色、蓝色边框和柔和阴影；任务主操作使用圆角描边按钮。
- 分组仅负责信息层级，不使用嵌套容器；单个学习任务使用独立圆角表面卡片。
- 窄屏下导航横向滚动，任务操作换行到内容下方，保证最小 40px 点击区域。

## 非目标

- 不修改学习任务、视频、试卷、历史成绩 API 契约。
- 不调整任务详情、学习小助手或全局导航。
- 不删除非待学习任务的数据。

## 验收

- 首次打开智慧课堂时向语文待学习任务发起查询。
- 所有学科切换不依赖下拉框，且只显示该学科的待学习任务分组。
- 390px、768px、1440px 下无文字遮挡、无横向内容溢出（学科导航除外）。
- 键盘可切换学科并打开任务；构建通过。
