# 学生学习内容：前端设计契约（Gate 3）

状态：已确认；新版上线前旧学习助手资料下线规则已纳入

## 1. 背景

现有学习小助手、智慧课堂和学习资料已有稳定路由。新能力必须在这些路由内演进，不能引入重复入口或客户端拼接持久化数据。

## 2. 目标

定义学生自学课件和统一错题本的页面职责、组件边界、状态模型与 API 使用边界。

## 3. 方案

### 路由与页面职责

| 路由 | 页面职责 | 数据边界 |
| --- | --- | --- |
| `#assistant/textbook` | 提交学生自学课件创建请求。 | 只提交教材 ID、章节 ID、当前学生；不生成内容。 |
| `#tutor/task/:taskId` | 解析任务并渲染学生自学课件。 | 只读取任务与其原课件实体；即时自检仅本地交互。 |
| `#resources/capture` | 渲染统一错题本。 | 只读取统一错题列表与原始详情链接；不写错题数据。 |

### 组件清单

| 组件 | 输入 | 职责 |
| --- | --- | --- |
| `StudentCoursewareReader` | 课件任务、学生课件步骤、关联测验任务。 | 进度、步骤阅读、即时自检、本地反馈与测验入口。 |
| `SelfCheckBlock` | 题干、选项或输入、解释。 | 非计分答案校验；不调用成绩 API。 |
| `UnifiedWrongBook` | 当前学生、筛选状态。 | 请求聚合列表，管理来源/学科/时间/关键词与局部重试。 |
| `WrongProblemSourceBadge` | 来源类型。 | 显示文本标签和对应图标/语义色。 |
| `WrongProblemListItem` | 标准化错题摘要。 | 根据来源显示正确详情入口和可用操作。 |

### 状态与请求边界

- 课件创建复用既有教材任务创建接口；服务端统一以学生自学结构保存新课件，客户端不得传递模式或版本来选择旧阅读器。
- 任务详情只渲染符合学生自学结构的教材课件；读取到删除后的旧学习助手目标或不存在的任务时渲染下线状态，不读取或猜测旧课件、测验或成绩数据。
- 统一错题本通过一个只读聚合接口获取标准化摘要；前端不得分别拉取数据库表后合并、去重或推断来源。
- 列表请求由筛选条件变化触发，使用取消/序号保护防止旧响应覆盖新筛选；失败时保留上一份成功数据和当前筛选。
- 课堂作答条目跳转到既有测验成绩详情，扫描条目复用既有错题详情；不创建新 Hash 顶级路由。

### 前端非目标

- 不在浏览器读取教材 Markdown、调用模型、写入课堂成绩或迁移错题。
- 不恢复、缓存或展示已删除的旧学习助手内容；不影响上传教材与上传试卷的原始查看路径。
- 不增加全局状态库或新路由框架。

## 4. 风险

- 若把删除后的历史课件当成读取失败而回退渲染旧数组，会重新暴露已下线内容；必须将目标缺失固定为下线状态。
- 若统一错题本继续只接收 `ScannedItem[]`，课堂来源必然无法显示；必须在 Gate 4 固定聚合响应契约。
