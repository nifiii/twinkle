# 已生成学习资料：UI/UE 设计契约

状态：Gate 3 已确认

## 1. 背景

复用学习资料现有的深色半透明表面、青蓝高亮、紧凑圆角与 Noto Sans CJK SC 排版，不为生成资料引入独立视觉主题。

## 2. 目标

使资料管理适合学生快速扫描，也让家长能明确判断删除影响。

## 3. 方案

- 使用现有 `cyber-surface`、`cyber-border`、`neon-blue` 令牌；状态同时采用文字和图标。
- 筛选采用固定高度分段按钮，不使用下拉框；窄屏允许水平滚动，不截断学科名称。
- 删除仅使用 `MoreHorizontal` 图标菜单中的 `Trash2` 命令，带 tooltip；确认按钮为红色文字按钮，取消为默认焦点。
- 卡片半径不超过现有 `rounded-xl`，一项一层，不在卡片内嵌套卡片。
- 桌面 1280、平板 768、手机 375 三视口中，资料标题换行但操作区稳定；触控目标最小 44px。

## 4. 风险

禁止以“整理”“移除”等含糊词替代删除；确认文案必须写明保留作答回顾和需巩固标记。
