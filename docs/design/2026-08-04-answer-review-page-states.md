# 作答回顾：页面状态（Gate 3）

## 1. 背景

回顾页不再有“批改中”状态，需清晰覆盖保存、读取和标记失败。

## 2. 目标

避免学生在提交后误以为系统仍在评分。

## 3. 方案

| 状态 | 表现 | 可执行动作 |
| --- | --- | --- |
| 提交中 | 提交按钮禁用，显示“正在保存作答” | 等待完成 |
| 提交成功 | 直接进入作答回顾 | 查看、标记需巩固 |
| 回顾加载 | 骨架屏，保留标题区域 | 等待、返回 |
| 回顾完整 | 每题四段内容与标记操作 | 标记/取消、返回 |
| 内容缺失 | 对缺少的参考答案或解析显示中性说明 | 仍可查看/标记 |
| 标记处理中 | 仅本题按钮禁用 | 等待 |
| 标记失败 | 本题下显示错误并恢复原开关状态 | 重试 |
| 记录不存在/无权 | 稳定错误页，无题目内容 | 返回上级 |

## 4. 风险

- 不得将旧 `grading`、`failed` 状态文案复用于新提交；它们属于已废弃的评分流程。
