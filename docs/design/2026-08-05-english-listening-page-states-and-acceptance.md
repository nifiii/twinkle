# 英语听力适龄与复听：页面状态与验收（Gate 3）

状态：待确认（变更控制）

## 1. 背景

验收必须证明内容来源、年级控制、解锁顺序和复听行为同时成立，不能只验证音频请求返回成功。

## 2. 目标

为学生听力流程定义稳定状态和可重复的服务、API、浏览器验收。

## 3. 方案

| 状态 | 页面表现 | 恢复规则 |
| --- | --- | --- |
| 初始 | 显示原创标识、章节、慢速默认、播放控制；题目和文本不在 DOM | 播放或重新加载。 |
| 音频加载 | 控件保持尺寸，说明正在加载当前速度 | 可取消或重试。 |
| 首播完成 | 显示题目与折叠文本，答案/解析仍隐藏 | 可作答或无限复听。 |
| 已提交 | 显示题目、学生答案、参考答案、解析与评分点 | 可无限复听与折叠文本；刷新后从服务端答案快照恢复。 |
| 音频失败 | 不改变已解锁状态，不虚报播放完成 | 仅重试当前速度音频。 |
| 任务失败 | 显示有限错误与返回智慧课堂 | 不显示半成品内容。 |

| ID | Given / When / Then |
| --- | --- |
| AC-EL-001 | 给定教材年级为 1、3、5 的上传英语教材和同一结构章节，当创建听力包时，服务分别保存基础、发展、提升能力档，模型输入只含章节标题、章节正文、教材年级和通用规则标识。 |
| AC-EL-002 | 给定任一听力创建请求，当输入不是当前可见英语教材章节或正文不足时，服务字段级拒绝，且不调用模型。 |
| AC-EL-003 | 给定 3-4 年级章节，当模型返回脚本超过发展档边界、题目类型不允许或缺少解析字段时，创建失败且不持久化半成品。 |
| AC-EL-004 | 给定基础、发展、提升三档成功包，当读取包时，均返回不可变 `gradeProfile`、`audioProfiles.slow` 和 `audioProfiles.standard`；它们的缓存身份不同。 |
| AC-EL-005 | 给定新听力包，当尚未完整播放时，题目、文本、答案、解析和评分点均不可见。 |
| AC-EL-006 | 给定新听力包，当第一次完整播放结束时，题目和折叠文本可见，答案、解析和评分点仍不可见；刷新后保持。 |
| AC-EL-007 | 给定任一听力包，当学生连续完成三次以上播放、暂停或重播时，所有播放控制持续可用，`completedPlays` 可增长但不再产生“次数已用完”。 |
| AC-EL-008 | 给定听力包，当学生在首播前后切换慢速/标准时，请求的速度档与实际缓存身份一致，切换不改变脚本、题目、答案或提交状态。 |
| AC-EL-009 | 给定已首播解锁的听力与 `{ "q1": "B" }` 作答，当提交时，服务端只接受当前包题目 ID 并原子保存答案快照；重复提交不覆盖首个快照，且不产生分数或批改数据。 |
| AC-EL-010 | 给定已提交听力，当刷新或重新进入时，每题连续显示题目、学生答案、参考答案、解析和评分点；仍可无限复听。 |
| AC-EL-011 | 在 390px、768px、1440px 和键盘操作下，学生可完成播放、速度切换、首播解锁、文本折叠、作答、提交与重播；焦点和状态提示可见。 |

## 4. 风险

真实 TTS 的速度需要通过请求记录与音频缓存路径共同验证，不能只依赖页面选中态截图。
