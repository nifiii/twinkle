# 学习小助手重构：前端页面与交互契约（Gate 3）

状态：已确认（Gate 3）

上游：`2026-07-28-learning-assistant-business-requirements.md`（BR-001 至 BR-020）和 `2026-07-28-learning-assistant-prd.md`。

## 1. 背景

现有 `StudyRoom` 已包含教材和错题两种生成入口，`LearningHub` 包含听力、视频、思维和考试入口，`AIClassroom` 保存并阅读课件、测验和历史。三个页面对学生来说是同一件事的不同入口。新体验应将“开始生成”收敛到学习小助手，将“找到并继续完成”收敛到智慧课堂。

## 2. 目标

- 学生在两步内抵达“错题讲解与测验”或“教材章节学习”的有效操作。
- 我的看板、学习资料、学习小助手、智慧课堂在桌面和移动端均为固定顺序的顶级导航。
- 所有生成完成的内容只在智慧课堂的统一任务索引中发现，再跳入原有详情实体。
- 不保留学习中心的页面、标题、菜单或 `#learn/*` 历史访问能力。

## 3. 方案

### 3.1 路由与页面归属

| Hash 路由 | 页面 | 职责 | 旧路由处理 |
| --- | --- | --- | --- |
| `#dashboard` | 我的看板 | 查看概览并进入其他学习入口。 | 保持既有路由。 |
| `#resources/<library|capture>` | 学习资料 | 书架与错题资料管理。移除 workshop 子页。 | 保持既有资源路由。 |
| `#assistant` | 学习小助手 | 错题流、教材流、生成动作与当前选择。 | 新主入口。 |
| `#assistant/wrong` | 学习小助手错题流 | 自动学科归类、人工修正、错题选择和生成。 | 新深链，仅承载页面状态。 |
| `#assistant/textbook` | 学习小助手教材流 | 教材/章节选择和学科能力动作。 | 新深链，仅承载页面状态。 |
| `#tutor` | 智慧课堂任务中心 | 聚合任务、筛选、继续学习、历史查看。 | 保持顶级入口。 |
| `#tutor/task/:taskId` | 智慧课堂任务解析页 | 读取统一任务索引并进入其原有详情实体。 | 新深链。 |
| `#learn/*` | 不存在 | 返回应用级“页面已下线”状态，不重定向、不加载旧实体。 | 明确不兼容。 |

`#assistant` 默认打开有可用错题的错题流；没有可用错题时默认教材流。用户主动切换后，本次会话保持其选择。

### 3.2 页面一：学习小助手

页面只有一个主任务：选择来源并创建一次学习任务。不可把智慧课堂历史、PDF 下载或大段课件阅读嵌入本页。

```text
页头：学习小助手 + 当前学生 + 资料上下文
来源切换：错题讲解与测验 | 教材章节学习
主工作区：对应流的选择与生成
底部行动条：已选范围/题目数 + 生成动作
```

#### 错题流

1. 默认依据错题本和课堂作答结果显示自动识别出的学科及数量。
2. 学生用学科切换控件改变筛选；切换不修改原始错题归类。
3. 学生从可读的错题列表勾选一至多题，可排除误识别项。
4. 固定行动条持续显示“已选题数、知识点数、预计生成内容”。
5. 点击“生成讲解与测验”后，创建一条新任务；成功后保留当前选择摘要，并给出“去智慧课堂查看”的明确命令。

列表的每题应展示来源、题号/短标题、识别学科、知识点、状态；题干过长时展开阅读，不能只截断关键条件。

#### 教材流

1. 先选当前可见的已归档教材；教材应标注学科、年级和共享状态。
2. 再选具体章节。目录层级在抽屉或选择器中浏览，确认后以单行可编辑摘要显示。
3. 章节确认前不显示可执行生成按钮；确认后按学科显示可用能力。
4. 所有学科显示“课件生成、随堂测验”；英语额外显示听力测试、视频学习、模拟考试；数学额外显示思维训练、视频学习、模拟考试；语文和科学显示视频学习、模拟考试。
5. 奥数模拟考试仅在匹配年级的上传奥数资料可用时出现。没有合格公开视频时，视频动作展示为不可执行的资源空状态，不能创建任务。
6. 点击任一动作创建独立新任务，不覆盖之前生成的内容。

“模拟考试”先进入范围/类型/难度配置，再生成任务。其他能力可在点击后直接创建，若后端需要异步生成，界面保留当前选择并展示任务进度。

### 3.3 页面二：智慧课堂

页面主任务是发现、继续和回看任务，而非重新配置生成范围。

```text
页头：智慧课堂 + 当前学生
快速区：继续学习（最多 3 条）
筛选栏：状态、学科、任务类型、教材/章节
任务列表：任务元信息、进度、来源锚点、主操作
详情：#tutor/task/:taskId 解析后进入原实体详情
```

任务类型采用固定标签：课件、随堂测验、错题讲解与测验、听力测试、视频学习、思维训练、模拟考试。任务状态采用：生成中、待开始、进行中、已完成、生成失败、资源不可用。

每条任务只展示一个主操作：生成中为“查看进度”，待开始/进行中为“继续”，完成为“查看结果”，失败为“重试”，资源不可用为“查看原因”。删除或重新生成不放在卡片主操作区，避免误触并保留不可变历史。

### 3.4 组件边界与数据责任

| 组件 | 数据/输入 | 负责 | 不负责 |
| --- | --- | --- | --- |
| `AssistantSourceSwitch` | 可用错题数、教材可用性、当前流 | 切换错题/教材流与 URL 状态 | 加载或生成内容。 |
| `WrongProblemPicker` | 自动归类错题、作答错题 | 学科筛选、人工校正、选题摘要 | 修改原始识别资料。 |
| `TextbookChapterPicker` | 可见教材、目录 | 教材/章节选择和无效元数据提示 | 生成任何实体。 |
| `SubjectActionGrid` | 学科、章节、能力可用性 | 展示和触发允许的生成动作 | 绕过后端能力校验。 |
| `GenerationActionBar` | 选择摘要、生成状态 | 禁用条件、异步反馈、进入课堂命令 | 任务内容详情。 |
| `ClassroomTaskHub` | 统一学习任务索引 | 筛选、分组、继续学习、历史发现 | 复制或重写原有实体。 |
| `TaskDestinationResolver` | `taskId` | 校验任务状态并跳入课件/测验/学习包/试卷详情 | 生成新任务。 |

### 3.5 前端 API 边界

- 已有课件、测验、学习包、试卷、诊断 API 保持其详情与作答职责；学习小助手只调用其公开生成入口。
- 统一任务索引在 Gate 4 定义为新的读取/写入契约；前端不得根据现有多张表拼接任务列表，也不得复制内容实体。
- 视频 API 只消费后端返回的已审核、健康、适龄且可嵌入资源。浏览器不搜索第三方视频，不拼接 URL，不保存第三方凭据。
- `ownerId` 作为当前家庭学生档案的资料上下文传递；首期前端不提供登录、角色或成员授权界面。
- 生成的异步状态仅在 `queued` 或 `running` 时轮询；终态停止。网络错误最多重试 3 次，重试使用同一请求幂等键或明确创建新任务。

### 3.6 状态与转场

| 触发 | 进入状态 | 结果 |
| --- | --- | --- |
| 打开助手 | 加载来源概览 | 默认进入错题流或教材流。 |
| 选题/章节不完整 | 校验状态 | 生成按钮禁用并给出字段级原因。 |
| 发起生成 | 创建中 | 行动条锁定，保留选择摘要。 |
| 创建成功 | 成功状态 | 新任务进入智慧课堂，显示进入命令。 |
| 创建失败 | 可重试失败 | 原选择保留，不创建伪任务。 |
| 视频无资源 | 资源空状态 | 无生成按钮与无任务创建。 |
| 打开课堂任务 | 任务解析 | 进入原实体，或显示失败/资源不可用原因。 |

完整页面状态与验收用例另见 `2026-07-28-learning-assistant-page-states-and-acceptance.md`。

### 3.7 响应式与无障碍

- 390px：来源切换和学科筛选允许横向滚动；行动条固定在安全区域上方；任务列表为单列，所有按钮文本完整换行。
- 768px：教材选择与章节摘要两列，行动网格两列，课堂筛选可换行。
- 1440px：助手采用主工作区与窄侧栏摘要；课堂采用快速区加高密度任务列表，列表不嵌套卡片。
- 所有操作可通过键盘触达；分段控件使用 `role=tablist` 或单选语义，选题使用真实复选框。
- 抽屉、对话框和任务详情解析中的焦点必须锁定并恢复；加载、生成、成功和失败用 `aria-live=polite` 通知。
- 不以颜色单独表达任务状态；图标、文字和状态标签同时存在。

## 4. 风险

- 删除 `#learn/*` 会让浏览器历史失效；路由必须显示明确的下线状态，不能悄悄打开旧内容。
- 现有错题生成以单题保存课件和测验为主；新多题任务需由统一任务索引承担聚合，不能在前端假装合并为一个实体。
- 现有课堂页同时承载课件、测验、错题与历史；若不先建立任务中心，继续堆叠 tab 会让移动端无法扫描。

## 5. 回滚

可独立关闭学习小助手入口和任务中心读取。原课件、测验、学习包、试卷、诊断和学习资料实体不迁移、不删除。按 BR-002，回滚不恢复旧学习中心 URL。

## 6. FAQ

### 为什么学习小助手不直接展示全部课堂历史？

生成与继续学习是不同任务。把历史塞回生成页会降低学生找到开始动作的速度，也会让错题流和教材流的选择状态难以恢复。

### 为什么视频不可用时不显示“试试生成”？

视频是审核过的第三方公开资源，不是模型生成物。无合格资源时重新生成不会产生可播放内容，应直接说明资源为空。
