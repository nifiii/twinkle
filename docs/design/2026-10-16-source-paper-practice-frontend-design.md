# 母卷原创测试：前端设计

## 1. 背景

Gate 3待确认。依据[PRD](../plans/2026-10-16-source-paper-practice-prd.md)、[页面状态](2026-10-16-source-paper-practice-page-states.md)及[视觉规范](2026-10-16-source-paper-practice-ui-ux-design-system.md)。复用React、TypeScript、Tailwind和现有API服务层，不引入新路由器、状态管理库或设计组件库。

## 2. 目标

独立表达母卷来源和结构确认，保持教材/错题入口，将既有奥数能力置于更名后的“模拟考试”内；状态、材料和题数受公开契约驱动，不用前端拼造假章节或模拟服务端成功。

## 3. 方案

### 3.1 路由和页面所有权

| 路由 | 责任 |
| --- | --- |
| `#assistant` / `#assistant/textbook` | 沿用默认教材章节学习；明确试卷排除规则；不改默认入口 |
| `#assistant/wrong` | 现有错题讲解与测验 |
| `#assistant/exam`（本轮提议） | 复用更名后的“模拟考试”入口；内部母卷出题/奥数模拟两模式，默认母卷模式；按模式展示对应表单 |
| 奥数模式 | 在模拟考试内可访问，保留既有来源、参数、创建契约与业务行为，不冒充母卷分析 |
| `#tutor/task/:id`及既有新版详情路由 | 显示生成结果、作答及回顾；按现有任务链接选择实际详情 |
| 学习资料生成资料页 | 复用现有路由，展示来源/学科/完成状态，沿用删除 |
| `#learn/*` | 继续下线，不重定向、不读取旧内容 |

新路由名属于Gate 3提案，Gate 4与前后端任务契约一起冻结。URL不携带正文、原题、答案或API密钥；刷新仅恢复选择或查询已受理请求，不自动重新分析/生成。

### 3.2 组件边界

| 责任单元（建议名，允许合并/调整） | 输入/输出边界 |
| --- | --- |
| 现有`LearningAssistant`页面壳 | 当前学生、当前tab、导航回调；三个入口，旧奥数tab更名为模拟考试，内部维护母卷/奥数模式；入口复用但来源和处理流程区分 |
| `SourcePaperPanel` | 负责本轮流程、选中来源、分析状态、确认草稿与任务恢复；仅处理当前学生上下文 |
| `PaperSourcePicker` | 候选资料与选中ID；呈现标题/学科/源年级/解析状态/范围；不分析正文 |
| `PaperStructureEditor` | 经核验结构、母卷题数、编辑草稿、校验结果；发出数量更改事件；不保存新题或自行识别类型 |
| `PaperGenerationSummary` | 当前学生/有效年级、来源范围、最终分区/题量；确认生成；不能独立发第二次创建 |
| 现有进度组件或最小扩展 | 真实阶段、耗时、原请求身份、终态、5分钟锁定；支持重连与焦点管理 |
| 现有任务/试卷阅读组件 | 新试卷已确认的题组/材料数据；渲染材料、题目、选项、作答及回顾，不回读母卷原题 |

优先在既有模块局部扩展，表中是责任而不是强制新增文件清单；不能为每个表单字段建一层透传组件。

### 3.3 数据获取与后端边界

现有`services/learningAssistantApi.ts`承担调用适配；具体方法、路径、JSON和错误码在Gate 4确认，本文不捏造已存在API。

| 能力 | 前端需要的数据 | 服务端必须负责 |
| --- | --- | --- |
| 候选查询 | 来源ID、标题、学科、源年级、解析状态、范围、来源版本标识 | 明确来源分类及可见性；仅前端过滤不足以拒绝错误来源 |
| 母卷分析 | 结构身份、来源版本、分区/题型、题组/子题数、知识点、必需材料状态、年级适配结果 | 从完整正文分析与核验；识别缺项；不只截前若干字，不把原题全文放入摘要 |
| 创建原创测试 | 已确认分析身份、当前学生、各分区题数；返回可恢复请求/任务身份 | 校验来源/分析新鲜度、有效年级、数量、原创生成及完整性；记录生成时快照、幂等性 |
| 状态查询 | 受理/处理阶段、终态、任务入口、可理解失败原因 | 权威任务状态、未知请求的核验、重试边界；不能用前端超时推定后端失败 |
| 结果/下载/删除 | 沿用既有公开详情和生成资料契约的兼容扩展 | 题组材料与题号完整、答案关联、状态一致、删除不涉及上传母卷 |

ownerId仍为家庭成员身份关联，不宣传安全隔离；不新增认证体系。API应执行既有来源可见性及档案关联校验，避免跨学生响应误显示。

### 3.4 本地状态与失效

- 状态归属分三类：服务端分析/任务真相、本地数量草稿、临时UI展开与焦点；不复制多份服务端完成状态。
- 分析结果绑定“当前模式 + 当前学生 + 来源ID/版本 + 分析身份”；请求使用单调序号或等效机制拒绝过期响应。换模式/换学生/换卷后清空旧编辑草稿和未提交分析，已生成任务保持独立。刷新恢复已受理任务时同时恢复其模式，不将奥数请求恢复成母卷请求。
- 题数字段可保留编辑中的空字符串，只有合法正整数才形成待提交配置；总数由配置计算，前后端均校验；不在输入时擅自取整。
- 候选刷新失败不清空当前可识别来源。源文件版本变化后必须重新分析，不沿用旧题量确认。
- 创建前保留可恢复意图身份；刷新可找到原已受理任务。恢复机制只存必要身份信息，不在浏览器存母卷正文/整卷新答案。存储位置、期限由Gate 4选择最小可行方案。
- 结果未知时禁止直接重发创建。服务端确认未受理或明确失败后才显示相应恢复/重试动作；失败重试保留原配置，不自动改题数。
- 客户端生成等待5分钟解锁不会取消服务器任务；切换页面后任务仍可在智慧课堂查到。

### 3.5 查询、重试、错误和材料展示

优先复用既有任务状态查询机制。若使用轮询，设计基线为前台3秒起、逐步退避至15秒；断网/后台暂停密集查询，恢复前台先查一次；终态、离页或上下文失效时停止。请求不得重叠，服务端限流/重试建议优先；精确查询预算在Gate 4冻结。不会用轮询再次调用模型。

分析失败的重试是显式业务动作，需说明可能重新分析；列表失败的重试只查列表。错误显示安全文案，不直接展示供应商原始响应或堆栈。结构/材料错误逐项定位到分区；新题题量或材料完整性未通过时，不进入可作答详情。

长标题和知识点自然换行；独立摘要不新建母卷全文预览。新生成阅读材料在所属题组前展示，选择题选项完整显示；图片必须有有效材料与适当替代说明，不能只有失效URL。听力若属于本次可核验范围，须由Gate 4明确与现有听力呈现/音频契约的兼容，不能以普通阅读框静默替代听力题型。

### 3.6 测试面和兼容边界

- 服务公开接口：错误来源拒绝、完整内容读取、结构/数量、年级快照、请求去重、失败无可见半成品。
- 页面行为：选卷无章节、摘要确认、非法输入、换学生响应竞态、5分钟解锁、刷新恢复与焦点。
- 现有详情/列表：作答提交后两处列表及刷新均“已完成/查看作答”，不回归“不可用/继续学习”。
- 现有PDF与答案快照：题组材料可独立阅读，答案对应；查看旧试卷和旧作答不依赖新增结构字段。
- 响应式和键盘检查按视觉规范执行；本轮无构建/浏览器执行证据，不能把设计检查计作功能通过。

不在本轮重构全部学习助手，不改教材目录结构，不扩扫描来源，不调整旧奥数蓝图，不恢复评分或视频。

## 4. 风险

现有固定题型和同步生成接口不能直接承载本设计。Gate 4必须稳定动态题组结构、有界生成和任务恢复后才能实施；若必须修改旧契约，应给出旧卷兼容及回滚路径，并同步验收而非静默放宽校验。
