# 英语听力适龄与复听：UI/UX 设计契约（Gate 3）

状态：待确认（变更控制）

## 1. 背景

听力页面必须与学习资料和智慧课堂的明亮学习工作台一致，不能因为音频交互单独使用深色播放器或娱乐化视觉。

## 2. 目标

让小学学生一眼分清“正在听”“可以作答”“可查看文本”“提交后可回顾”，并能用最少操作调整速度。

## 3. 方案

- 沿用 `2026-07-28-learning-assistant-ui-ux-design-system.md` 的画布、字体、颜色和 6/8px 圆角令牌。
- 页面首区使用“英语听力 / AI 原创 / 教材章节”紧凑信息行；能力档仅写“适合四年级学习节奏”这类学生语言，不展示课程标准编号或技术速度值。
- 播放控制为稳定尺寸工具条：播放/暂停图标按钮、重新开始图标按钮、`慢速 0.75x | 标准 1.00x | 加快 1.10x` 分段控件。教材年级决定初始激活项；控件最小触控目标 44px。
- “查看听力文本”是折叠阅读区，不是弹窗；首播前不渲染其正文。展开后脚本使用 16px、1.65 行高、最大阅读宽度 720px。
- 理解题使用连续纸面式题组，提交操作固定在题组末尾；禁止把题目、文本和答案分别堆进嵌套卡片。
- 速度状态必须同时以文本和选中态表达，不能只靠颜色；音频加载中保留按钮尺寸并显示状态文本。

视觉验收：在 390px、768px、1440px，长章节名换行但不挤压播放控件；速度切换、文本折叠和提交均有清晰焦点环和读屏名称。

## 4. 风险

若把文本区始终预渲染再以 CSS 隐藏，屏幕阅读器或浏览器查找可能提前暴露内容；实现必须在服务端进度允许后才在 DOM 中提供文本。
