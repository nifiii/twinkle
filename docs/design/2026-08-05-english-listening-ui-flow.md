# 英语听力适龄与复听：用户流程（Gate 3）

状态：已确认；2026-10-10 按用户要求变更为提前看题、固定 5 题。

## 1. 背景

听力页允许学生先阅读题干和选项，再带着问题听；听力原文在首播完成后显示，参考答案在提交后显示。

## 2. 目标

让学生从智慧课堂任务详情进入后，以固定且可预测的顺序完成播放、辅助阅读、作答与回顾。

## 3. 方案

```text
智慧课堂听力任务
  -> 显示教材章节、原创标识、年级适龄提示、慢速/标准/加快
  -> 同时显示理解题与选项（新包 5 题，旧包原题数），可预先选择
  -> 播放（可暂停、重播、无限复听）
  -> 首次完整播放结束
  -> 保留已选答案，解锁折叠的听力文本与提交按钮
  -> 作答并提交
  -> 显示每题答案、解析与评分点；仍可变速复听与查看文本
```

| 阶段 | 可见 | 禁止/隐藏 | 主操作 |
| --- | --- | --- | --- |
| 初始 | 原创标识、章节、能力档说明、速度切换、播放控制、题目与选项 | 文本、参考答案、解析；提交禁用并提示需完整听完 | 先看题、选择答案、播放 |
| 首播完成 | 题目、折叠文本、速度切换 | 答案、解析、评分点 | 作答、再次播放 |
| 已提交 | 题目、学生答案、答案、解析、评分点、文本 | 无播放次数锁定 | 回顾、再次播放 |
| 音频失败 | 已生成的题目状态与选择摘要 | 不伪造已播放 | 重试音频 |

键盘：空格或 Enter 操作聚焦的播放、暂停、重播及速度控件；文本折叠控件使用原生 `details/summary` 或等价可访问语义。播放结束时焦点不自动跳转，使用 `aria-live=polite` 提示“已可开始作答并查看听力文本”。

## 4. 风险

文本是理解辅助而非答案提示，因此必须在首播完成后才显示，且提交前不可含任何答案、解析或评分信息。
