# 作答回顾：前端实现设计（Gate 3）

## 1. 背景

现有测验详情和试卷诊断页分别消费评分结果，需要收敛到同一“作答回顾”展示模型。

## 2. 目标

前端只读取回顾快照与需巩固状态，不计算对错、分数或评分状态。

## 3. 方案

| 区域 | 前端职责 |
| --- | --- |
| 作答提交 | 成功后以返回的 attempt/result ID 跳转回顾详情；不轮询批改。 |
| 回顾详情 | 渲染 `question`、`studentAnswer`、`referenceAnswer`、`explanation`、`needsReinforcement`。 |
| 标记动作 | 调用专属标记接口，乐观更新仅限当前题；失败回滚并展示错误。 |
| 历史列表 | 展示学科、资料、章节、完成时间与“作答回顾”入口，不取评分字段。 |
| 看板 | 删除掌握率和成绩趋势组件/请求字段消费，保留待学习、待完成与教师批注错题。 |

前端不得自行从题库推断对错，也不得用旧 `isCorrect`、`percentage`、`diagnosis` 字段做兼容分支。

## 4. 风险

- 旧 API 缓存可能含评分结构，切换用户或重新提交后必须按 ownerId 和记录 ID 重新请求回顾数据。
