# 已生成学习资料：UI 流程

状态：Gate 3 已确认

## 1. 背景

页面是家庭学习软件的重复使用型资料管理界面，延续“学习资料”的页头、Tab 和低干扰阅读语言。

## 2. 目标

让学生在两步内定位、继续或下线自己生成的学习内容。

## 3. 方案

```text
学习资料 → 已生成 → 学科 / 进度筛选 → 继续学习
                                └→ 更多 → 删除确认 → 已下线提示
智慧课堂失败任务 → 显示教材资料原因 → 返回学习资料修复
```

页面结构：欢迎条下第三个子 Tab“已生成”；筛选条为学科分段控件和进度分段控件；结果为单层列表卡，每项有类型图标、标题、教材/章节、时间、状态和“继续学习”。删除置于每项更多菜单，确认弹窗不嵌套卡片。

## 4. 风险

删除动作不能靠颜色或图标单独表达；键盘焦点进入确认弹窗后必须锁定在弹窗内，取消后返回触发按钮。
