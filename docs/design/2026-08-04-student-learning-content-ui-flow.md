# 学生学习内容：用户流程（Gate 3）

状态：已确认；新版上线前旧学习助手资料下线规则已纳入

上游：`docs/plans/2026-08-04-student-learning-content-prd.md`。

## 1. 背景

学生需要在不理解内部数据来源的前提下，完成章节自学并在一个错题本中回看所有学习错误。

## 2. 目标

将“章节学习”和“错题回看”变成两个短路径：前者从学习小助手创建并在智慧课堂完成，后者从学习资料发现并回到正确的原始记录。

## 3. 方案

### 流程 A：创建并完成学生自学课件

```text
#assistant/textbook
  -> 选择教材和一至多个具体章节
  -> 点击“生成学生自学课件”
  -> 创建学习任务
  -> #tutor/task/:taskId
  -> 学习目标 -> 知识点步骤 -> 即时自检 -> 易错提醒 -> 小结
  -> “进入随堂测验”
  -> 原随堂测验作答与学习诊断
```

规则：即时自检可跳过；入口显示“建议先完成自检”，不阻断正式随堂测验。

### 流程 B：统一错题本回看

```text
#resources/capture
  -> 错题本默认“全部来源”
  -> 使用来源、学科、时间、关键词筛选
  -> 打开一条错题
  -> 拍题归档：原扫描错题详情 / 可编辑操作
     课堂作答：原测验成绩的逐题详情 / 只读
```

### 页面归属

| 路由 | 主任务 | 不承担的任务 |
| --- | --- | --- |
| `#assistant/textbook` | 选择教材章节并创建新课件任务。 | 阅读完整课件、编辑历史课件。 |
| `#tutor/task/:taskId` | 继续学生自学课件并进入随堂测验。 | 重新选择教材范围、修改诊断成绩或回到已下线的历史教材课件。 |
| `#resources/capture` | 浏览统一错题本和进入原始详情。 | 创建学习任务、把课堂错题迁移为扫描记录。 |

### 流程 C：旧学习小助手资料下线

```text
旧课程、测验、模拟考试或学习任务地址
  -> 请求目标实体
  -> 目标不存在 / 任务已删除
  -> “该学习内容已下线”
  -> 返回智慧课堂
```

规则：不重定向到新内容，不显示旧课件、测验、成绩或错题详情，不提供恢复、重新打开或历史访问入口。用户上传教材和上传试卷的原始查看路径不受影响。

## 4. 风险

- 将课堂错题做成与扫描错题相同的编辑卡，会误导学生并破坏来源边界；课堂来源只显示查看成绩详情。
- 在课件阅读页放入完整测验会混淆自检和诊断；仅提供明确的测验入口。
