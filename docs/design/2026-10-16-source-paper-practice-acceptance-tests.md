# 母卷原创测试：验收用例

## 1. 背景

Gate 3待确认，2026-10-16。依据[PRD](../plans/2026-10-16-source-paper-practice-prd.md)及本轮四份设计文档。沿用AC-SP-001～010作为验收组；细例采用后缀，新增AC-SP-011～014覆盖交互与恢复。全部为待执行用例，不是测试通过报告。

## 2. 目标

以真实用户路径与公开接口验证来源、结构、数量、年级、原创、完整性及历史兼容。测试不能只断言函数返回相同字段。

### 2.1 合成示例资料

| 数据ID | 输入 | 预期用途 |
| --- | --- | --- |

| FX-SP-E | 完整40子题长母卷，分区10/10/20，最后分区材料位于旧截取长度之外 | 大于10题，全文覆盖与长输出验证 |
| FX-SP-F | 普通教材、奥数资料、扫描作业、普通归档试卷各一份 | 来源候选与服务端边界 |

## 3. 方案

### 3.3 执行与证据标准

- 公开API测试：合成母卷及有界供应商故障响应验证结构、错误来源、数量和状态；不能只mock全部业务层后声称完整通过。
- 浏览器：真实本地服务执行关键路径、三视口和键盘检查，检查网络请求及刷新后的持久状态；计时器可控测试5分钟阈值，另核验真实任务恢复。
- 模型：合成完整20题与40题验证真实结构理解、完整生成、参考答案解析和原创抽样；区分合成请求与用户资料外发授权，记录脱敏请求身份/耗时/终态，不打印原文或密钥。
- PDF：实际下载新卷及答案卷，逐页核对材料、分页、题号和答案，保存渲染检查记录；仅HTTP 200不能证明可用。
- 发布证据应列用例ID、环境/提交、输入夹具、命令或步骤、观察结果、失败分类、证据路径。未知/未执行不能写通过。

本轮完成一次“产出→挑战→修订”文档复核：

| 发现 | 修订/结论 |
| --- | --- |

## 4. 风险

当前代码不满足本轮动态母卷蓝图，以上用例须在Gate 4稳定题型及材料结构、长卷预算、任务恢复、API错误码后落到实现任务；不应把技术未实现归咎于用户资料缺失。新增支持边界若改变已确认“默认与母卷题量一致”，必须回PRD确认，不能只在UI添加限制。
