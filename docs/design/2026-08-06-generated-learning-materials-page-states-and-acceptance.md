# 已生成学习资料：页面状态与验收

状态：Gate 3 已确认

## 1. 背景

状态必须区分“没有生成内容”“筛选无结果”“生成内容已下线”和“教材资料需修复”。

## 2. 目标

页面在读取、筛选、删除和失败任务场景中不给出误导性操作。

## 3. 方案

| 状态 | 展示 | 操作 |
|---|---|---|
| 加载 | 稳定高度加载状态 | 无重复请求。 |
| 无资料 | “还没有已生成学习资料” | 引导至学习小助手。 |
| 筛选为空 | “当前筛选没有资料” | 清除筛选。 |
| 删除确认 | 保留范围说明 | 取消/确认删除。 |
| 删除成功 | 本行移除、提示已下线 | 保留筛选。 |
| 删除阻断 | 共享内容或回顾快照不完整原因 | 不删除。 |
| 听力资料错误 | “教材年级/章节正文需修复” | 无重新生成按钮。 |

| ID | Given / When / Then |
|---|---|
| AC-GLM-001 | Given 两个学科的 ready 任务，When 选英语，Then 仅显示英语。 |
| AC-GLM-002 | Given 待学习和已完成任务，When 切换进度，Then 结果按 `learningStatus` 精确过滤。 |
| AC-GLM-003 | Given 可删除的生成课件，When 确认删除，Then 资料页和智慧课堂不再列出，旧地址返回 410。 |
| AC-GLM-004 | Given 删除资料关联作答回顾，When 删除，Then 回顾与需巩固标记仍可读取。 |
| AC-GLM-005 | Given 共享实体或缺少回顾快照，When 删除，Then API 拒绝并无数据变化。 |
| AC-ELR-001 | Given `grade=小学`，When 打开失败听力，Then 显示资料修复原因且无重试按钮。 |
| AC-ELR-002 | Given 修复后的三年级下册教材，When 新建听力，Then 使用 g3_4 档并成功生成。 |

## 4. 风险

验收必须覆盖 1280、768、375 宽度和键盘删除确认流程。
