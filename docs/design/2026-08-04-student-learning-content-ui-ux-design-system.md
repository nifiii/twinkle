# 学生学习内容：UI/UX 设计系统补充（Gate 3）

状态：已确认；新版上线前旧学习助手资料下线规则已纳入

## 1. 背景

本次新增内容必须与学习资料和智慧课堂使用同一页面语言，避免学生在“课件”和“错题本”之间切换时重新学习界面。

## 2. 目标

让小学阶段学生快速识别“现在学什么、下一步做什么、错题来自哪里”，同时保持家长可扫描的信息密度。

## 3. 方案

### 视觉方向

- 产品类别：家庭学习工作台；重复使用、以阅读和任务完成为主。
- 方向：安静、清晰、略带学习感；复用现有 `cyber-*` 表面、边框、正文与 `neon-*` 语义色。
- 不新增渐变背景、独立主题、装饰插画或嵌套卡片；页面保持一个主工作区，重复条目才使用卡片。

### 信息层级与组件

| 组件 | 规则 |
| --- | --- |
| 学习步骤导航 | 固定显示“第 N / 总步骤”和短标题；使用进度条，不用大号幻灯片页码。 |
| 知识点步骤 | 标题、解释、示例、自检依次排列；一屏只有一个核心知识点。 |
| 即时自检 | 使用“想一想”图标与非计分标签；提交后展示解释，不使用分数、排名或警示红色。 |
| 随堂测验入口 | 仅在课件小结后作为唯一主按钮；使用 `ClipboardCheck` 图标。 |
| 错题来源标签 | “拍题归档”使用现有中性蓝；“课堂作答”使用现有紫色；必须含文字，不能只依赖颜色。 |
| 错题条目主操作 | 拍题归档为“查看错题”，课堂作答为“查看测验详情”；不显示误导性的编辑或删除按钮。 |
| 筛选 | 来源采用分段控件：全部、拍题归档、课堂作答；学科、时间、关键词保留现有控件语义。 |
| 下线状态 | 使用现有中性说明面，短文本“该学习内容已下线”，只提供返回智慧课堂；不使用错误红色、旧课件/测验/成绩预览或重定向。 |

### 排版与响应式

- 内容阅读列最大 `760px`；统一错题列表最大 `1120px`。
- 1440px：阅读步骤与知识点目录可双栏；错题筛选与列表同页。
- 768px：阅读单列，筛选可换行；来源分段控件保持一行。
- 390px：步骤进度、标题和主操作单列；关键词和下拉筛选分行；来源标签不得被截断。
- 字体沿用 Noto Sans CJK SC；正文最小 `16px`、行高至少 `1.65`；不使用视口缩放字体或负字距。

### 可用性与无障碍

- 键盘顺序：来源筛选 → 学科/时间/搜索 → 错题列表 → 详情操作；课件为进度摘要 → 正文 → 自检 → 上/下一步。
- 所有图标按钮有中文 `aria-label` 和悬停提示；可点击区域至少 `44px` 高。
- 焦点环使用现有高对比蓝色；禁用状态说明原因；错误信息以文本而非颜色单独表达。
- 尊重减少动态效果设置；步骤切换仅使用短淡入，不产生布局位移。

### 视觉验收

- 在 390px、768px、1440px 截图检查：长章节标题、来源标签、筛选器、即时自检解释和主操作无重叠。
- 检查键盘焦点、禁用“生成”状态、单来源失败的部分成功状态及课堂错题只读状态。

## 4. 风险

- 课堂错题使用扫描错题的红色“错误/删除”视觉会让学生误解可编辑性；必须使用独立来源标签和只读详情操作。
