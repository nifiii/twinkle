# 作答回顾：用户流程（Gate 3）

## 1. 背景

本流程替代课堂测验和试卷提交后的批改、成绩与改判路径。

## 2. 目标

让学生在提交后立即核对并自主决定哪些题需要巩固。

## 3. 方案

```text
作答页 -> 提交 -> 保存作答快照 -> 作答回顾
                                  -> 每题：题目 / 我的答案 / 参考答案 / 解析
                                  -> 标记需巩固 <-> 取消需巩固
                                  -> 返回智慧课堂或试卷列表

学习资料错题本 <- 仅读取“需巩固”的课堂题 + 教师批注错题
```

- 提交成功不显示“正在批改”，直接进入作答回顾。
- 每题的“需巩固”是独立按钮，切换后立即更新本题状态；失败时恢复原状态并显示可重试提示。
- 历史记录打开同一回顾页，不显示任何评分区域。
- 缺少参考答案或解析时，保留题目与学生答案，显示中性缺失提示；不阻断查看或标记。

## 4. 风险

- 一题一开关必须避免误触；按钮有明确的已标记状态与撤销动作，不能仅靠颜色传达。
