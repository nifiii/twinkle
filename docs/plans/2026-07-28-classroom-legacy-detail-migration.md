# 智慧课堂旧详情迁移计划

## 背景

`#tutor/courseware`、`#tutor/quiz`、`#tutor/wrong` 和 `#tutor/history` 是旧智慧课堂页面的多入口列表。新版智慧课堂已提供统一任务索引，但课件阅读、课堂测验作答和旧测验成绩详情仍跳转到旧页面。

## 目标

- `#tutor` 成为学习任务和历史内容的唯一入口。
- 在 `#tutor/task/:id` 内渲染课堂课件、课堂测验和历史测验成绩。
- 历史测验成绩加入统一任务索引，保留原记录和二次改判能力。
- 旧 `#tutor/courseware/*`、`#tutor/quiz/*`、`#tutor/wrong/*` 与 `#tutor/history/*` 地址显示下线状态，不读取旧内容。

## 方案

1. 扩展课堂任务查询，将 `quiz_results` 作为只读历史任务摘要和详情来源。
2. 在任务详情按 `primaryLink.entityType` 读取现有课堂内容或测验成绩；复用既有课件语音、课件章节、测验作答和测验提交 API。
3. 将课件与测验提交后的回流地址固定为新任务详情或智慧课堂，不再生成旧路由。
4. 路由层将旧课堂的 `courseware`、`quiz`、`wrong` 与 `history` 路径进入下线页；新版学习包和试卷详情仍由智慧课堂任务承载。

## 风险

- 历史数据格式不完整时详情必须呈现可理解的不可用状态，不能让页面崩溃。
- 旧课件语音播放依赖现有静态音频与学习标记 API，迁移时需保持调用参数不变。
- 历史测验可能没有关联教材 ID；索引只按其保存的书名、章节、学科展示，不伪造教材关系。

## 回滚

恢复旧 `#tutor/*` 路由分发即可继续使用旧阅读器；数据表和历史记录均不删除，不需要数据回滚。

## 验收

- 统一索引能列出历史课件、课堂测验和历史测验成绩。
- 三种详情均只在 `#tutor/task/:id` 打开。
- 课堂测验提交后能回到新版详情或索引，成绩可见且可逐题改判。
- 旧 `#tutor/*` 地址显示下线状态且不读取内容。
