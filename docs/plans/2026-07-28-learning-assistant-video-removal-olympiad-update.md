# 学习小助手：奥数试卷与视频下线更新

## 1. 背景

学习小助手的奥数模拟考试曾作为教材章节试卷的可选模式，因此会要求选择教材章节并读取章节正文。视频学习同时存在于新建任务、资源查询与历史详情播放中，页面视觉也没有遵循学习资料的页面语言。

## 2. 目标

- 奥数模拟考试只选择已归档、标注年级的奥数资料，不选择教材或章节。
- 奥数命题只使用资料的标题、年级、类别和标签组织原创题；不读取、保存或发送奥数资料正文。
- 停止视频资源查询、新视频任务创建和站内视频播放；历史视频记录可查看下线说明。
- 学习小助手与学习资料使用同一页头、圆角标签栏、色彩层次和响应式行为。

## 3. 方案

- `source.kind = olympiad` 创建独立试卷任务，任务来源快照保存奥数资料，不写入章节。
- 教材试卷仍要求已上传教材的有效章节；两条路径不共用章节校验。
- 奥数蓝图以奥数资料 ID 作为资料锚点，`chapterIdsJson` 保存空数组；生成阶段不读取 Markdown，也不传 `textbookExcerpt`。
- 从章节动作和学习包允许列表中删除视频能力。旧视频任务与旧视频学习包保留数据，但详情仅显示“视频学习已取消”。
- 学习小助手增加“按章节学习 / 奥数模拟考试”二级切换；奥数界面只显示资料、试卷类型和难度。

## 4. 风险

- 历史视频任务仍在任务索引中可见，但无法播放。这是保留历史记录与取消功能之间的明确兼容边界。
- 奥数资料缺少年级、数学学科或奥数分类时不可被选用，避免错误地将普通教材作为竞赛命题来源。
- 新任务来源增加 `olympiad`，任务详情读取和列表必须兼容该类型。

## 5. 回滚

恢复视频需要重新确认第三方资源审核、播放和隐私边界，并单独恢复资源 API、创建路径和播放页。奥数独立来源可回退为关闭入口，不删除已生成的试卷或任务。

## 6. FAQ

### 为什么奥数试卷不再选择章节？

奥数资料自身才是知识范围与难度风格的来源；要求选择普通教材章节会引入不相关正文，也会让任务来源与实际命题依据不一致。

### 为什么历史视频不再播放？

已取消视频功能后继续嵌入第三方链接会保留不可控的外部内容入口。历史记录保留用于学习轨迹查看，但不再请求或渲染外部视频。
