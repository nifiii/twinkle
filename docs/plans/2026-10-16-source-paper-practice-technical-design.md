# 母卷原创测试：技术设计与实施边界

## 1. 背景

依据已确认PRD及Gate 3设计。2026-10-16用户明确要求“按照文档进行代码实现，然后推送master”；该授权包含当前范围内常规技术选择、契约补齐及实施，不扩大来源、评分或生产数据操作范围。

已确认根因：普通试卷只因不是奥数就进入教材候选；旧命题蓝图固定9/10题且不能表达组合材料。采用独立母卷适配器，复用任务、试卷、作答与导出，保持旧蓝图校验不变。

## 2. 目标

来源可校验、完整正文分析、结构确认、当前学生年级快照、有界分批生成、整卷原子保存、刷新恢复；不新增全局菜单、评分或外部题库。

## 3. 方案

- 前后端共用纯分类规则：category/tags明确包含试卷、试题、测试卷等来源标记，且非奥数/数学竞赛；不用标题硬判。教材任务服务及旧直接命题API同时拒绝此类来源。
- 新增`source_paper_analyses`表存请求身份、来源版本哈希、目标年级、结构摘要、状态/错误、最终taskId；不存母卷正文或原题全文。源版本哈希覆盖正文和影响分析的元数据。
- 正文读取完整文件；超过180000字符明确拒绝，绝不截取前缀冒充完整。摘要含范围、知识点、分区题型、作答模式、可作答子题数、题组数、材料需求及缺项。分析结果与当前学生/有效年级绑定。
- 题型标签保留选择、阅读、完形、配对、判断、写作、计算、应用等含义；choice/fill/essay仅作为答题控件模式。题组材料及题组ID随原创小题保存，网页、回顾与PDF均展示。无法核验的题型、缺图片或听力原文均阻断；未能提供可用音频的听力分区不得当普通阅读发布。
- 有效年级按既有用户档案学年口径计算，但缺有效基准/生日时拒绝兜底年级。任务和试卷保存创建时年级，旧卷不回读当前档案重写。
- 分析请求和生成均立即受理后异步执行，查询只读不触发模型。ownerId用于家庭成员关联，不作为安全边界。
- 每分区最多8子题一批，逐批生成独立完整材料。只发结构摘要与已确认配置给出题模型，不发送母卷原题；整卷校验数量/材料/题号/参考答案解析后一次事务写入蓝图、试卷与链接。模型单次120秒、最多一次纠正重试，整次生成15分钟执行上限；5分钟仅解除页面锁定。失败无可见半成品。
- 原创性校验包含源文连续长片段重合检测；另需合成资料真实模型抽样验证，不能声称机器检查证明绝对原创。
- 分析同ownerId+requestKey唯一，创建同ownerId+requestKey幂等；事务内再次核验并发标识冲突。同analysisId只允许一个当前任务，明确失败可重试；刷新从浏览器保存的请求身份及已确认数量配置查询，未知受理仅能重发原标识和原配置。后台状态未知不新建请求。单实例进程重启将旧运行中分析/母卷任务显式标记失败，不自动再调用模型。
- 现有列表/详情基于任务和paper_attempts提交事实判完成；新来源扩展为`source_paper`，chapterIds为空且只能assessment。删除沿用生成资料契约，母卷不删。
- 旧卷schemaVersion=1原样读取，新卷schemaVersion=2增加可选material/groupId/questionKind；旧接口不改变必填字段。无破坏性迁移。
- 当前纯文字答题支持单项选择、填空、文字问答及带完整文字材料的阅读/完形/配对；音频、看图/绘图和多选分区明确阻断，不改成其他题型。生成题若引用短文，必须附带完整material，即使源分区标为独立题也保留该材料；图片依赖、材料中未关联子题的编号空格均拒绝发布。以上为完整性门槛，不证明所有模型内容语义正确。

### 3.1 使用与发布

学习小助手→模拟考试（默认母卷出题）→选母卷→分析→确认各分区子题数→生成→智慧课堂作答/回顾。奥数模拟为内部另一模式，参数及旧命题逻辑不变。

沿用现有任务/试卷feature flags、.env模型配置、A4字体及Docker流程。部署前备份SQLite；新增表自动建立。回滚应用保留新表，不删除上传文件；旧版本不能创建source_paper任务，新任务仅由新版访问。

### 3.2 测试面

公开服务/HTTP接口验证来源拒绝、全文末尾知识点、20/40子题、缺材料/不确定、年级差异、失效分析、去重、失败无半成品、长任务非5分钟误失败。网页三视口和键盘验证；PDF实际渲染与答案快照；旧教材/奥数/错题回归。真实模型仅用合成数据。

## 4. 风险

动态题型、长输出和异步任务为主要风险；受支持结构不能被静默降级。真实资料缺图/缺原文时应返回明确阻断。执行超限显式失败，不改题数求成功。GitNexus impact已执行但部分图查询为UNKNOWN，影响面以源码调用方补齐，不能将0条边当作无影响。
