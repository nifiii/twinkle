# 学生学习内容改造 PRD（Gate 2）

状态：已确认；新版上线前派生学习数据清理变更已纳入

上游依据：

- `docs/requirements/2026-08-04-student-self-study-courseware-business-requirements.md`（BR-SSC-001 至 BR-SSC-012）
- `docs/requirements/2026-08-04-unified-wrong-book-business-requirements.md`（BR-UWB-001 至 BR-UWB-007）

## 1. 背景

教材章节课件的当前结构不足以确保学生能独立学习，学习资料的错题本又缺少课堂作答错题。两项问题共同降低了“学生发现问题 → 理解知识点 → 练习验证”的闭环完整性。

## 2. 目标

1. 新创建的教材章节课件让学生能围绕选定章节独立理解、练习和进入随堂测验。
2. 学习资料的错题本完整呈现学生的拍题归档错题与课堂作答错题，并保留来源语义。

## 3. 方案

### 3.1 MVP 范围

| 领域 | 必须能力 |
| --- | --- |
| 教材章节学习 | 新课件按学生自学结构生成，包含目标、知识点讲解、示例、自检、易错提醒、小结和同章节测验入口。 |
| 课件阅读 | 明确学习步骤、即时自检反馈、学习进度与进入随堂测验的行动；不展示教师话术。 |
| 智慧课堂 | 新任务标识为学生自学课件，保留教材、章节、学习进度和测验关联。 |
| 学习资料错题本 | 两来源统一列表、来源标签、跨来源筛选、原始详情跳转与独立加载错误状态。 |
| 上线清理 | 删除全部既有学习小助手派生资料与关联记录；保留用户上传教材、用户上传试卷及其源文件。 |

### 3.2 用户故事

| ID | 用户故事 | 优先级 |
| --- | --- | --- |
| US-SLC-001 | 作为学生，我选择教材章节后获得可自己学习的讲解，而不是教师备课内容。 | Must |
| US-SLC-002 | 作为学生，我能逐步理解知识点，并在课件内做不计分的即时自检。 | Must |
| US-SLC-003 | 作为学生，我完成课件后能进入同章节随堂测验检验掌握程度。 | Must |
| US-SLC-004 | 作为学生，我在学习资料错题本能看到拍题和课堂作答产生的错题。 | Must |
| US-SLC-005 | 作为学生，我能知道每道错题来自哪里，并回到正确的原始记录。 | Must |
| US-SLC-006 | 作为家长，我能在新版服务上线后保留所有上传教材和上传试卷，但不再访问旧学习小助手资料。 | Must |

### 3.3 非目标

- 不保留任何旧学习小助手课件、测验、模拟考试、成绩或任务详情入口。
- 不删除 `books`、`scanned_items.type='exam_paper'`、其他非错题扫描资料或关联源文件。
- 不将课件即时自检计入成绩、排名或掌握率。
- 不将课堂错题写入扫描错题表或旧错题关联表。
- 不修改已有随堂测验的出题、批改、复核、PDF 或成绩计算规则。
- 不新增教师备课、直播授课、实时答疑或跨家庭共享能力。

### 3.4 页面与功能清单

| 页面 | 变更 |
| --- | --- |
| `#assistant/textbook` | 新创建课件采用“学生自学课件”语义，保留教材与具体章节选择。 |
| `#tutor/task/:taskId` 与课件详情 | 阅读新版学生自学步骤、完成自检、进入同章节随堂测验；任何已清理旧学习助手任务显示“该学习内容已下线”，不提供旧阅读器或替代入口。 |
| `#resources/capture` → 错题本 | 聚合拍题归档与课堂作答错题，显示来源、筛选、详情入口和各来源加载状态。 |

### 3.5 成功与发布标准

- 新课件不含教师备课或授课指令，且通过结构校验后才能保存。
- 删除迁移在 `--dry-run` 阶段输出数据库和专属文件备份位置、待删派生实体、待删文件、保留源资料计数和阻断项；存在阻断项时 `--apply` 失败且不写数据库或文件系统。
- `--apply` 后，旧学习小助手课件、测验、模拟考试、作答、成绩、错题和任务均不可读取；`books`、上传试卷和其他非错题扫描资料及源文件计数与校验值不变。
- 四学科各使用一段真实已归档教材章节验证学生自学结构与学科示例。
- 同章节随堂测验能从新课件进入，成绩仍按原诊断链路记录。
- 错题本与学习小助手均展示符合条件的两类错题；课堂错题不出现在 `scanned_items` 或旧错题统计中。
- 390px、768px、1440px 视口下课件步骤、错题来源标签、筛选和详情入口均可操作；键盘焦点可达。

### 3.6 待确认决策

| ID | 决策 | 建议默认值 | 影响 |
| --- | --- | --- | --- |
| D-SSC-002 | 即时自检是否必须完成才可进入随堂测验？ | 不强制；显示建议先完成自检。 | 课件进度、测验入口状态和验收用例。 |
| D-SSC-003 | 单章节课件的建议长度。 | 6 至 10 个学习步骤、10 至 20 分钟。 | 生成结构校验、阅读页分页/进度与模型成本。 |

## 4. 风险

| 风险 | 处理方向 |
| --- | --- |
| 模型输出仍偏教师 | 以结构化学生课件契约、禁用内容校验和生成失败重试约束。 |
| 全量清理误伤上传资料 | 学习助手派生数据与用户上传试卷共用数据库和文件存储。 | 保留源资料白名单、备份与 dry-run；试卷/教材计数和文件 SHA-256 不变才允许提交。 |
| 两来源错题列表产生误删或误跳转 | 来源类型决定可用操作与详情路由，课堂记录不提供扫描记录编辑/删除操作。 |
| 章节正文不足 | 沿用教材解析有效性校验，拒绝生成并引导回教材解析。 |

## 5. 回滚

迁移前关闭全部学习小助手创建入口。删除后如需恢复，只能停止新课件创建，并从本次迁移生成的数据库与专属文件备份恢复；恢复前必须先停服务并验证备份校验值。上传教材与上传试卷不参与恢复，因为它们不应被删除。
