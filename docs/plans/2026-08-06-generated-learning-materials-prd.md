# 已生成学习资料管理 PRD

状态：Gate 2 已确认

## 1. 背景

家庭上传资料与系统生成学习内容混在不同入口，学生难以回看、筛选和清理不再需要的生成内容。历史英语听力失败任务还误导学生反复重试。

## 2. 目标

在“学习资料”新增“已生成”页，按学科和学习进度管理已生成内容；删除生成资料而不删除学生作答回顾、需巩固标记或家庭上传原件；消除历史英语听力无效重试入口。

## 3. 方案

### MVP

| 用户故事 | 交付 |
|---|---|
| US-GLM-001 学生查找内容 | 在学习资料进入“已生成”，按学科、全部/待学习/已完成筛选。 |
| US-GLM-002 学生继续学习 | 每项资料直接进入既有任务详情。 |
| US-GLM-003 学生清理内容 | 通过确认弹窗下线当前生成资料，明确保留作答回顾和需巩固。 |
| US-GLM-004 学生理解失败 | 英语听力教材资料不完整时展示原因，不提供无效重试。 |
| US-ELR-001 维护者修复历史 | 备份、审核清单后更新三年级英语结构化年级并删除无内容的失败听力任务。 |

### 页面与优先级

1. `#resources/generated` 已生成学习资料，Must。
2. 智慧课堂失败状态提示，Must。
3. 生产历史听力修复脚本和运行手册，Must。

### 非目标

- 不删除上传资料，不批量新建或重建听力。
- 不增加多账户安全隔离、恢复站或批量删除。
- 不把已完成作答回顾重新挂回被删除任务入口。

### 成功标准

- `ready` 生成任务可按两类筛选准确列出并继续学习。
- 删除后任务/生成实体返回下线状态，作答回顾和错题标记仍可读。
- 历史 12 条失败听力经审核后不再出现；修复教材后新建三年级听力可通过年级校验。

## 4. 风险

- 关联实体可能被多个任务引用：API 必须拒绝删除并返回可读原因。
- 作答回顾可能依赖试卷内容：删除前必须验证回顾快照完整。
- 生产迁移不可逆：必须 dry-run、备份、manifest 审核和 `--apply` 分离。
