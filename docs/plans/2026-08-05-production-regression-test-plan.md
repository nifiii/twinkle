# 生产环境回归测试计划

## 1. 背景

生产环境已有教材、学习任务、学习包和试卷。回归测试必须以真实家庭学生路径验证这些资料可发现、可继续学习、可回顾，不能以本地 mock 代替。

## 2. 目标

- 用可重复的脚本覆盖健康检查、资料、章节能力、任务中心、课件、听力、试卷、作答回顾和 PDF 导出。
- 只读模式不改变生产数据；写入模式只创建新的原创学习任务，不删除教材、试卷、用户或历史记录。
- 每次运行生成本地脱敏 JSON 报告，记录通过、失败、跳过和新建任务 ID。

## 3. 方案

入口：`scripts/production-regression.mjs`。

```text
node scripts/production-regression.mjs
node scripts/production-regression.mjs --write
```

默认目标为 `https://dd.haokuai.uk` 和 `child_1`；可用 `PRODUCTION_BASE_URL`、`PRODUCTION_OWNER_ID` 覆盖。`--write` 依次创建教材课件、英语听力和教材模拟考试，并等待每项 API 终态；随后会请求听力三档真实音频，创建并提交一份最小试卷作答、标记一题“需巩固”、导出一份 A4 试卷。生成结果保留在智慧课堂供人工验收。

| 场景 | 只读 | 写入 | 断言 |
| --- | --- | --- | --- |
| 健康与当前学生 | 是 | 否 | 服务健康、学生和教材可读。 |
| 教材与章节能力 | 是 | 否 | 四个学科教材均有目录，返回的动作符合学科边界。 |
| 智慧课堂索引 | 是 | 否 | 任务详情可读，同一原实体只出现一个索引条目，无长期 `running` 任务。 |
| 学生课件 | 是 | 否 | 课件任务同时关联课件和随堂测验。 |
| 英语听力 | 是 | 否 | 听力包有 0.75、1.00、1.10 三档受控音频契约。 |
| 模拟考试 | 是 | 否 | 试卷任务能读取试卷实体。 |
| 原创生成 | 否 | 是 | 课件、听力、试卷均从当前教材章节创建并在任务中心可读。 |
| 听力音频 | 否 | 是 | 三档受控语速均实际返回可播放 MP3。 |
| 作答回顾与 PDF | 否 | 是 | 作答可提交、题目/学生答案/参考答案/解析连续可读、需巩固可写入、A4 PDF 可下载。 |

## 4. 风险

- 写入模式会消耗模型额度并留下可见学习任务；不可用于压测或并发重试。
- 写入模式会提交一份最小作答、标记一题“需巩固”并创建一份 PDF；这些记录会留在当前学生资料中，运行前需确认这是可接受的验收痕迹。脚本不删除任何生产数据。
- 模型生成没有内部进度事件，脚本仅记录 HTTP 时长和最终任务状态。
