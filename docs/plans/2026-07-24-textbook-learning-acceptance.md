# 教材驱动学习与测评：验收测试（Gate 3/7）

状态：已验证（2026-07-27；证据见 [发布证据与回滚包](2026-07-24-textbook-learning-release-evidence.md)）

## 1. 背景

验收覆盖“教材范围正确、原创且合规、考试可用、评分可解释、旧功能不回归”五条主线，不能以模型返回成功代替用户行为验证。

## 2. 目标

为 BR-001 至 BR-011 提供可自动化或手工复核的明确门禁，并定义发布前证据。

## 3. 方案

### 3.1 验收场景

| AC-002 | 给定教材缺少学科、年级或目录，当学生尝试生成资源/试卷时，那么系统阻止提交并指出缺失字段。 | BR-001 |
| AC-003 | 给定单设备内切换学生 A/B，当当前资料上下文为 B 时，学习中心、最近任务和新学习入口只展示 `ownerId=B` 的数据；切回 A 后恢复 A 的数据。该用例不验证服务端认证或跨学生安全隔离。 | BR-011 |
| AC-004 | 给定英语教材章节，当学生创建听力练习时，那么产物含 AI 原创标识、脚本、音频、题目、答案和评分点；首播时题目隐藏。 | BR-002 |
| AC-005 | 给定听力练习，当学生完成一次播放时，服务端记录该 `ownerId + packageId` 的播放次数；完成两次后，第三次完整播放不可用。提交后服务端记录提交状态，文本与解析才可查看；刷新页面后状态保持。 | BR-002 |
| AC-006 | 给定 `reviewedAt` 为空或 `linkHealthStatus` 不为 `healthy` 的视频链接，当查询学习包时，那么该链接不显示为可学习资源；给定 `reviewedAt` 非空且健康有效的链接，则返回标题、来源、时长、适龄标签和 URL，新窗口打开且不传递学生信息。 | BR-004, BR-011 |
| AC-006a | 给定英语教材章节和一条已审核且健康的英语公开视频链接，当创建英语视频学习包时，那么返回该资源；不创建科学视频包，也不返回其他学科链接。 | BR-004 |

| AC-008 | 给定单元范围，当学生选择基础/标准/挑战之一时，那么生成前蓝图显示题型、题数、分值、总分、难度与范围，默认标准。 | BR-005, BR-006 |
| AC-009 | 给定未审核广州风格摘要，当生成试卷时，那么生成教材原创卷且不显示广州风格标签；给定已审核摘要，则输出仍不含样本原题全文。 | BR-007, BR-008 |
| AC-010 | 给定一份网页试卷，当学生刷新、返回后再进入时，那么草稿可恢复；提交确认后不能误重复创建作答。 | BR-006 |
| AC-011 | 给定填空题的全半角、大小写、等价数学符号或多个可接受答案，当学生作答等价内容时，那么按规范化/备选答案判分；非等价包含关系不得误判满分。 | BR-009 |
| AC-012 | 给定解答题“过程正确但最终计算错误”，当批改时，那么过程评分点得分、结果评分点失分，结果显示证据与理由。 | BR-009 |
| AC-013 | 给定解答题“文字不同但满足同一量规”，当批改时，那么不得仅因表达不同扣分；低于 0.75 置信度时标为建议复核。 | BR-009, BR-010 |
| AC-014 | 给定已批改诊断，当家长提交复核或手动改判时，那么保留原评分、改判前后结果、原因、操作者类型和时间，并重算诊断分。 | BR-010 |
| AC-015 | 给定结构化原创试卷，当用户下载时，那么获得 A4 试卷和答案卷两份 PDF；页码、中文、题号、数学公式、答题区和分值不重叠。 | BR-006 |
| AC-016 | 给定旧章节测验、旧测验历史、旧课件和错题，当新功能上线后，那么旧 API/深链仍可读取和完成原有流程。 | 保护现有功能 |

### 3.4 发布证据

- 自动测试命令、退出码与运行时间。
- 新旧 API 的请求/响应样例（脱敏）。
- 桌面、平板、手机截图；两份 PDF 的渲染截图。
- `detect_changes()` 输出，确认仅覆盖本次预期符号和流程。
- Spec 审查、标准审查和 UI/UE 审查各自的结论；任何 P1/P2 未解决问题阻止发布。

## 4. 风险

不能用模型自身生成的参考答案验证模型阅卷。主观题验收必须使用预先人工写定的量规和对照作答，包括同义、等价步骤、过程对结果错、结果对过程缺失和无关作答。

## 5. 回滚

任一本地资料上下文切换、版权标识、PDF 可读性或主观题证据测试失败，停止灰度并关闭对应能力开关；旧章节测验保留为可用路径。若部署环境不再是受信任的单设备本地环境，也必须停止新学习路由发布。

## 6. FAQ

### 为什么要把低置信度题目视为未完成诊断？

学习诊断的价值来自可解释性。无法给出稳定评分证据时，系统应请求复核，而不是伪装成精确分数。
