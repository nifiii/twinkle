## 1. 背景

当前系统已支持教材上传、目录提取、章节课件生成、章节测验、错题归档和测验历史。学生需要从教材快速进入英语听力、数学思维、科学视频、复习资料与符合学校考试风格的试卷，并需要更公平地批改主观题。

## 2. 目标

建立一条以教材、年级、学期和章节为边界的学习与测评闭环。学生能在最少操作内进入对应资源或测试；家长能理解题目范围、难度、得分依据和薄弱点。

### 3.2 已确认输入、输出与成功标准

| 维度 | 已确认内容 |
| --- | --- |
| 输入 | 学生上传或归档的教材、年级、学科、章节、学习目标、难度、学生作答过程。 |
| 输出 | AI 原创英语听力练习、第三方视频链接、原创奥数/学科测验、复习大纲、正式试卷风格原创测验、过程性批改结果。 |
| 成功标准 | 学生可基于对应教材快速获得资源或测验；题目范围、难度、题型和评分依据可追溯；主观题不因同义表述被机械扣分；自动分数仅用于学习诊断且可逐题复核。 |

### 3.3 现有能力与差距

| 能力域 | 当前状态 | 本次差距 |
| --- | --- | --- |
| 教材定位 | 书籍保存年级、学科和目录，可选择章节。 | 缺少统一的教材版本、学期、知识点和资源映射。 |
| 课件 | 已可按章节异步生成并保存。 | 无视频资源检索、可信来源与教材锚点。 |
| 测验 | 已支持 1/2/3 星、选择题/填空题/解答题和历史记录。 | 无单元/期中/期末试卷蓝图、试卷版式、题型模板和真题风格来源。 |
| 阅卷 | 已支持自动判定和人工二次改判。 | 解答题无评分点、步骤证据、分步得分、置信度或申诉流程。 |

### 3.4 复杂度与范围风险

- 内容版权与数据来源：教材、音视频和广州试卷都需要可用的授权或公开来源，不能以模型生成内容冒充真题。
- 教学准确性：没有教材版本、年级和学期，任何“基于课本”的覆盖声明都不可验证。
- 评分可信度：主观题必须保存评分依据和过程证据，不能只返回布尔正确性。
- 未成年人数据：学生作答、音频、学习画像应最小化存储，并限制家长和学生账户的可见范围。

## 4. 风险

现有题目模型只有题干、答案和解析，无法表达正式试卷结构和过程性评分。若直接在现有接口上堆叠字段，会让题型、批改和历史数据不可维护；后续设计必须采用向后兼容的数据模型。

## 5. 回滚

后续功能以新增资源、试卷与评分版本为主，不覆盖历史课件、题目或测验结果。若新题源、评分或页面异常，可关闭对应入口并继续使用现有章节测验和人工改判。

## 6. FAQ

### 为什么尚未开始实现？

“教材内容来源”和“真题来源”决定版权、数据质量、接口和验收边界。该规则未确认前，生成 PRD 与技术方案会产生不可执行的假设。
