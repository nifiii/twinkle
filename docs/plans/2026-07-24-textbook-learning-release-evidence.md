# 教材驱动学习与测评：发布证据与回滚包（T-013）

状态：可在受信任的单设备本地环境灰度；公网生产验证受阻，见 [生产学习功能验证记录](2026-07-27-production-learning-validation-report.md)

## 1. 背景

本包汇集教材驱动学习与测评能力的发布门禁。首期的 `ownerId` 仅用于本地资料选择和记录归属，不能作为身份、授权或跨学生安全隔离机制。任何公网或多账户发布都必须先完成身份上下文和服务端授权设计。

本证据中的通过结论仅覆盖隔离验收容器，不能外推为公网生产环境已启用新学习能力。当前生产环境的开关保持关闭，完整数学学习链尚未在生产执行。

## 2. 目标

证明新学习域不破坏既有书架、AI 课堂、章节测验、错题和历史记录，并使学习中心、原创试卷、诊断复核和 A4 下载具备可回溯的验收与回滚路径。

### 3.3 PDF 与字体证据

- 生成服务注册并嵌入 `backend/assets/fonts/NotoSansCJKsc-Regular.otf`。
- 字体遵循 SIL Open Font License 1.1；来源、许可链接和用途见 `backend/assets/fonts/NOTICE.md`。
- `Dockerfile` 在后端构建阶段复制 `backend/assets`，生产镜像从构建阶段复制该目录，因此字体随镜像发布。
- PDF 测试夹具覆盖中文、MathJax SVG、短题和跨页解答题；服务端页眉包含原创标识、教材范围、版本及日期。

### 3.5 逐能力回滚

1. 关闭受影响能力开关，停止该能力的新建请求，保留已有学习记录、试卷和审计事件只读。
2. 停止新学习域灰度入口；旧书架、章节测验、AI 课堂、错题和历史路由保持开放。
3. 若开关无法隔离问题，回退到上一已知可用应用镜像和同版本前端资源。
4. 仅在确认数据损坏时，使用发布前数据库副本恢复；追加式学习域表默认保留，禁止为回滚删除学生记录。
5. 验证旧章节测验、`quiz_results`、`#dashboard`、`#resources/library`、`#tutor/history`，并保留脱敏日志与审计事件供根因分析。

## 4. 风险

- `ownerId` 可由客户端输入，不能抵御不受信任访问者；这是已确认的单设备范围，而非安全缺陷修补的替代方案。
- 自动阅卷分数只用于学习诊断。低置信度或无证据题目必须进入复核，不得转换为正式成绩。
- 第三方视频仅链接到已审核且健康的公开资源；健康状态变化时停止展示链接。
- PDF 字体为受控镜像资产。构建时若缺失字体或许可证说明，阻止发布。

## 5. 回滚

按“关闭能力开关 -> 停止灰度 -> 回退镜像 -> 验证旧路径 -> 保留审计证据”执行。禁止删除学习域新表或批量删除学生生成内容来制造回滚成功。

## 6. FAQ

### 能否直接发布到公网或多账户环境？

不能。该范围缺少可信身份与服务端资源授权；必须先新增认证、授权和受控下载契约，并重新执行跨学生越权验收。

### 字体是否随镜像发布？

是。Noto Sans CJK SC 的 OTF 资产位于 `backend/assets/fonts/`，Docker 生产阶段会复制该目录；许可证说明同目录随镜像发布。
