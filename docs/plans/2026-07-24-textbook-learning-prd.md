# 教材驱动学习与测评 PRD（Gate 2）

状态：已确认，基于 BR-001 至 BR-011

## 1. 背景

学生当前需要在书架、AI 课堂和错题记录间切换，不能快速将一个教材章节转为学习资源、正式试卷或复习计划。现有测验仅有三种题型，主观题只有二元对错，无法表达考试卷和过程得分。

## 2. 目标

新增“学习中心”，以教材章节为起点提供学习包、测评和复盘；生成的原创内容与外部链接、试卷与评分量规均可追溯。

## 3. 方案

### 3.1 MVP 与完整版本

| 范围 | MVP | 完整版本 |
| --- | --- | --- |
| 章节入口 | 从已补全的家庭共享或学生教材选择章节，展示四个行动：听力/视频/练习/测试。 | 从看板推荐继续学习和薄弱点复习。 |
| 英语听力 | AI 脚本 + TTS + 选择/填空理解题，两次播放。 | 听写、跟读、语速分档和错句复听。 |
| 视频 | 人工审核且健康有效的公开外链卡片，按学科/章节过滤；卡片包含标题、来源、时长和适龄标签。 | 家长来源偏好和学习完成记录。 |
| 数学与科学 | 数感/数形结合/方程等标签学习包；科学视频卡片。 | 错因驱动的跨章节学习路径。 |
| 测试 | 单元试卷、难度选择、原创题、网页考试、结果诊断。 | 期中/期末、复习大纲、广州风格摘要、A4 PDF 试卷和答案卷。 |
| 批改 | 客观题规范化，解答题评分量规、过程/结果分、低置信度提示、逐题改判。 | 复核理由、评分版本比较、家长批注和错因聚合。 |

### 3.2 不在范围内

- 平台内置教材、未经授权题库、教材原声和真题全文。
- 视频托管、下载、站内播放器或对第三方账户登录。
- 自动成绩作为学校正式分数、教师身份认证或班级排行。
- 跨学生服务端数据隔离、家庭共享授权或面向公网的多账户使用；首期仅支持单设备本地资料切换。
- 现有书架、拍题、错题、课件和测验历史的重写。

### 3.3 用户故事与优先级

| ID | 用户故事 | 优先级 |
| --- | --- | --- |
| US-001 | 作为学生，我选择教材章节后可立即开始听力、看视频、练习或测试。 | Must |
| US-002 | 作为学生，我可选择基础、标准或挑战难度再生成原创试卷。 | Must |
| US-003 | 作为学生，我能在网页端按正常考试卷阅读和作答，并下载 A4 试卷与答案卷。 | Must |
| US-004 | 作为学生，我能理解解答题每个得分点与扣分原因，而不因措辞不同被直接判错。 | Must |
| US-005 | 作为家长，我能逐题复核或改判诊断结果。 | Must |
| US-006 | 作为家长，我能看到单元/期中/期末的范围与复习大纲。 | Should |
| US-007 | 作为学生，我可使用上传奥数资料的年级范围完成原创竞赛风格练习。 | Should |
| US-008 | 作为系统管理员，我只录入审核过的外链和风格摘要。 | Should |

### 3.4 页面与功能清单

| 页面 | 主任务 | 关键能力 |
| --- | --- | --- |
| 学习中心 | 从教材开始一项学习任务 | 教材/章节选择、最近任务、四个高频入口。 |
| 学习包 | 消费听力、视频、复习大纲、数学思维资源 | 外链说明、音频控制、完成状态。 |
| 命题配置 | 生成可审查的原创试卷 | 范围、类型、难度、题型/分值蓝图、风格可用性。 |
| 网页考试 | 限时或自由作答 | 试卷式排版、题号导航、保存草稿、交卷确认。 |
| 试卷预览/下载 | 打印或下载 A4 试卷及答案卷 | 浏览器预览、PDF 下载、版本信息。 |
| 诊断与复核 | 理解得分并改判 | 评分点、过程证据、低置信度、复核操作、审计记录。 |

### 3.5 发布标准

- Must 用户故事与 `AC-001` 至 `AC-016` 全部通过。
- 不影响 `/api/generate-assessment`、`/api/classroom`、`/api/quiz-results` 现有调用和历史读取。
- 只展示审核成功且未失效的第三方视频链接；样本未审核时不出现对应风格标签。
- `ownerId` 仅用于本地资料选择和记录归属，不得宣称其提供登录、授权或跨学生安全隔离。

## 4. 风险

直接用现有 `Question` 结构扩展正式试卷会导致题型、分值、答题区和评分量规不可表示。MVP 必须先引入结构化试卷模型，再由旧章节测验渐进接入，不能修改旧 JSON 后假设历史结果仍可读。

首期没有可信身份上下文。将应用部署到可被不同用户直接访问的环境会使任何人能够改变 `ownerId` 读取另一资料上下文，因此新学习路由只能在受信任的单设备本地环境启用；多用户发布必须作为独立需求完成认证和服务端授权。

## 5. 回滚

新入口和新 API 使用能力开关。关闭后隐藏学习中心新卡片，旧 AI 课堂与历史测验继续可用；已生成试卷、PDF 和诊断以只读方式保留。

## 6. FAQ

### 为什么要在生成前显示难度？

难度会影响蓝图、题型分布与分值，生成后再改变会造成试卷与诊断口径不一致。
