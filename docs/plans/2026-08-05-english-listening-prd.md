# 英语听力适龄与复听 PRD（Gate 2）

状态：待确认（变更控制）

上游依据：`2026-08-05-english-listening-requirements.md` 的 BR-EL-001 至 BR-EL-008。

## 1. 背景

学生需要能听清、复听并在需要时查看听力文本，而非被固定播放次数或过快语速阻断。现有内容范围与原创边界保持不变。

## 2. 目标

在教材章节绑定的英语听力任务中，按教材年级生成适龄原创内容，支持慢速/标准/加快音频和无限复听；首播后帮助学生理解文本，提交后才揭示答案与解析。

## 3. 方案

### MVP 范围

| 能力 | 规则 |
| --- | --- |
| 适龄生成 | 从教材元数据取得年级，映射通用课程标准能力档，并把档位约束传给模型。 |
| 原创与范围 | 仅以选中上传教材章节作知识点锚点；输出不得复制教材完整句、广州外部内容或真题。 |
| 音频 | 默认按年级档选中慢速 `0.75x`、标准 `1.00x`、加快 `1.10x` 之一；学生可在三个固定档间切换，重复播放不设次数上限。 |
| 学习顺序 | 未完整播放时隐藏题目、文本、答案和解析；首播结束后题目可答、文本可折叠查看；提交后显示答案、解析和评分点。 |
| 历史兼容 | 不删除旧包或进度数据；旧包可无限播放，且首播后可读文本。 |

### 用户故事

| ID | 故事 | 优先级 |
| --- | --- | --- |
| US-EL-001 | 作为低年级学生，我打开听力时默认能听到较慢、句子较短的原创材料。 | Must |
| US-EL-002 | 作为学生，我能不限次数重听，并在慢速和标准之间切换。 | Must |
| US-EL-003 | 作为学生，我第一次完整听完后能展开文本辅助理解，但在交卷前看不到答案和解析。 | Must |
| US-EL-004 | 作为家长，我能确认听力只基于孩子上传教材章节和通用能力档生成，而非外部广州试卷。 | Must |

### 非目标

- 不接入、存储、检索或复现广州外部教材、试题、听力原文或公开卷。
- 不实现听写、跟读评分、口语识别、排行或学校正式成绩。
- 不重写教材选择、学习任务索引、题目作答或其他学科内容。

### 发布标准

- BR-EL-001 至 BR-EL-008 和 AC-EL-001 至 AC-EL-010 均有服务、API 或浏览器证据。
- 使用 1-2、3-4、5-6 三档夹具验证模型输入与输出结构；不向真实模型发送夹具外内容。
- 390px、768px、1440px 与键盘路径均可完成首播、速度切换、展开文本、提交与复听。

## 4. 风险

速度档会增加音频缓存量；以包 ID、脚本哈希、速度档与 TTS 配置版本构成缓存身份，避免旧音频混用。模型输出若不符合年级档结构，整个听力包失败，不保存半成品。
