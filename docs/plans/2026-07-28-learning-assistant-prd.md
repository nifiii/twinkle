# 学习小助手重构 PRD（Gate 2）

状态：已确认（Gate 2）

上游依据：`docs/requirements/2026-07-28-learning-assistant-business-requirements.md` 的 BR-001 至 BR-020。

## 1. 背景

学生当前要在学习资料、隐藏的小助手、学习中心和智慧课堂间切换。错题驱动学习与教材驱动学习的入口混杂，已生成内容也没有统一的课堂任务视图。

## 2. 目标

学生在独立的学习小助手中，以“错题”或“教材章节”快速发起合适的学习活动；每个成功生成的活动都可在智慧课堂中找到、继续和回看。

## 3. 方案

### 3.1 MVP 范围

| 页面 | 用户目标 | MVP 能力 |
| --- | --- | --- |
| 全局导航 | 快速进入正确学习入口 | 保留我的看板为首项，移除学习中心；桌面和移动端均按我的看板、学习资料、学习小助手、智慧课堂排列。 |
| 学习小助手 | 从错题或教材开始学习 | 两个互斥、清晰的入口流；显示当前学生资料上下文。 |
| 错题讲解与测验 | 解决已发生的错误 | 自动学科归类、人工更正、多题选择、逐题讲解、知识点归因、原创针对性测验。 |
| 教材章节学习 | 围绕课本章节学习 | 教材/章节选择；课件和随堂测验；按学科显示已确认能力矩阵。 |
| 英语听力测试 | 依据章节完成听力理解 | 原创脚本与题目；两次完整播放限制；播放完成后作答。 |
| 视频学习 | 观看合规视频并留存任务 | 仅嵌入审核合格的公开第三方视频；无资源时给出空状态。 |
| 模拟考试与诊断 | 以考试卷式完成原创测评 | 配置范围、类型和难度；网页作答、A4 试卷与答案卷、诊断、逐题复核与改判。 |
| 智慧课堂 | 聚合并继续学习 | 以统一任务索引显示进行中、最新、已完成和历史任务；进入原实体详情。 |

### 3.3 明确非目标

- 不保留学习中心导航、页面标题或旧 `#learn/*` 历史 URL。
- 不内置教材、不读取非学生上传或归档的教材正文。
- 不复制试卷、课件、学习包或作答实体到新仓库。
- 不站内托管、下载、代理、搜索或绕过限制播放第三方视频。
- 不提供跨家庭共享、登录、角色权限或多租户管理。
- 不将自动批改成绩作为学校正式成绩或排名依据。

### 3.4 用户故事与优先级

| ID | 用户故事 | 优先级 |
| --- | --- | --- |
| US-001 | 作为学生，我能从学习资料下面的独立学习小助手进入学习，而不再看到学习中心。 | Must |
| US-002 | 作为学生，我可从错题本和课堂错题中自动得到科目归类，并手动校正后生成讲解与测验。 | Must |
| US-003 | 作为学生，我可选择已上传教材的具体章节后生成课件或随堂测验。 | Must |
| US-004 | 作为学生，我能按当前学科看到听力、视频、思维训练与模拟考试等匹配能力。 | Must |
| US-005 | 作为学生，我每次生成后都能在智慧课堂找到独立的学习任务。 | Must |
| US-006 | 作为学生，我只会看到可在站内嵌入的公开、审核且健康的视频。 | Must |

### 3.5 成功与发布标准

- `BR-001` 至 `BR-020` 和 `US-001` 至 `US-010` 均有可验证的验收用例。
- 生成的每类内容在创建成功后都能从智慧课堂统一任务列表进入对应详情。
- 同一次重新生成不修改既有任务、作答、试卷版本或复核记录。
- 视频资源未同时满足审核、健康、适龄、公开和可嵌入条件时，不出现可执行入口且不创建任务。
- 390px、768px、1440px 页面均能完成两条核心流程；键盘可到达、选择和发起全部操作。

## 4. 风险

| 风险 | 处理方向 |
| --- | --- |
| 旧链接失效 | 发布说明明确不兼容；新导航的学习小助手和智慧课堂提供替代入口。 |
| 原实体与统一任务索引不同步 | 使用可重试、可观测的任务创建链路；任务详情需验证原实体仍可读取。 |
| 视频嵌入限制变化 | 审核记录持久化嵌入状态并定期健康检查；失效任务显示不可用状态而非嵌入失败空白。 |
| 误识别错题学科 | 提供学科切换与题目排除；生成前展示题目数量和知识点范围。 |
| 跨家庭范围扩张 | 当前没有角色或授权管理；需要跨家庭共享、公开多用户访问时，必须另立身份与授权需求。 |

## 5. 回滚

关闭新入口和聚合功能后，保留原实体数据和课堂历史；不恢复旧学习中心入口与旧 URL。任务索引可停止创建，但不得删除已生成的课件、试卷、作答或诊断。

## 6. FAQ

### 为什么智慧课堂只建索引而不复制内容？

课件、测验、学习包和试卷已有不同的版本、作答和评分语义。统一索引只承担发现与导航，能减少迁移风险并保留已有历史。

### 奥数模拟考试为什么会消失？

它只能基于学生上传、且标注为匹配年级的奥数资料生成。当资料不存在或年级不匹配时不显示，避免把普通教材卷误标为奥数卷。
