# 作答回顾：验收用例（Gate 3）

## 1. 背景

验收覆盖新旧作答回顾、需巩固标记、评分数据清理和上传资料保护。

## 2. 目标

确保“无自动批改”是可观察的端到端事实，而不仅是隐藏分数。

## 3. 方案

| ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-AR-001 | 一份含选择、填空、解答题的课堂测验。 | 学生提交任意答案。 | 响应同步完成；不调用模型；作答回顾逐题显示题目、学生答案、参考答案、解析。 |
| AC-AR-002 | 一份网页/A4 试卷已开始作答。 | 学生提交。 | 不写评分项、分数、得分率、学习建议、批改时间或复核事件；回顾内容可读取。 |
| AC-AR-003 | 一条已完成新作答回顾。 | 标记第 2 题“需巩固”。 | 该题进入统一错题本“课堂作答”来源，来源快照指向原作答及题号。 |
| AC-AR-004 | 第 2 题已标记需巩固。 | 取消标记。 | 该题从课堂错题本消失；同一作答其他题不变化。 |
| AC-AR-005 | 历史 `quiz_results`、`paper_attempts`、评分项和复核事件同时存在。 | 执行评分数据清理 dry-run。 | 生成备份、manifest、待删评分字段/行清单和保留回顾字段计数；不写数据。 |
| AC-AR-006 | AC-AR-005 无阻断项且 manifest 已审核。 | 执行 apply。 | 评分专属数据删除；历史回顾仍显示题目、学生答案、参考答案、解析；上传试卷、教材、教师批注错题及源文件哈希不变。 |
| AC-AR-007 | 新旧作答回顾与我的看板。 | 在 390px、768px、1440px 打开并键盘操作。 | 无分数、对错、批改或改判文本/图标；题目内容与标记操作不重叠，按钮可聚焦。 |
| AC-AR-008 | 模型服务不可用。 | 提交课堂测验或试卷。 | 提交与回顾成功，因为提交路径不依赖模型。 |

## 4. 风险

- 清理验收必须检查数据库和页面，不得只依赖 UI 隐藏。
