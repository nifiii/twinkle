# 基于母卷生成原创测试 PRD

## 1. 背景

关联[业务需求与偏差分析](../requirements/2026-10-16-source-paper-practice-business-requirements.md)。沿用Strict。Gate 2已于2026-10-16由用户“确认该范围”确认，非实现完成记录。

2026-10-16入口变更：用户要求复用现有按钮，“奥数模拟考试”更名为“模拟考试”，不新增“试卷出题”同级入口。本文及Gate 3已同步；其余已确认业务范围不变。

用户无法用没有章节的试卷发起原创测试。现有奥数入口也不分析资料正文；把试卷加入奥数选择框不能满足该需求。

## 2. 目标

### 2.1 用户故事

| ID | 用户获得的能力 | 关联规则 |
| --- | --- | --- |
| US-SP-001 | 在“模拟考试”的“母卷出题”模式选择母卷，不处理教材章节。 | BR-SP-001/007 |
| US-SP-002 | 查看母卷知识点、题型和题量摘要，确认系统理解正确。 | BR-SP-002/008 |
| US-SP-003 | 默认按母卷结构生成，也能在生成前调整各类题量。 | BR-SP-004 |
| US-SP-004 | 获得适合当前档案年级的原创测试，并在智慧课堂作答、回顾、下载。 | BR-SP-003/005/006 |
| US-SP-005 | 缺正文或材料时知道具体缺项，不得到伪完整试卷。 | BR-SP-009 |

### 2.2 已确认MVP范围

- 优先覆盖截图所在的学习资料归档库：已归档、已解析、明确分类或标注为试卷的资料。首期学科为现有语文、数学、英语、科学。
- 小助手同级入口固定为“教材章节学习 / 错题讲解与测验 / 模拟考试”。复用并更名现有“奥数模拟考试”入口，内部以“母卷出题 / 奥数模拟”切换两种来源模式；不新增第四个入口，不重新设计整站。进入模拟考试默认展示母卷出题；奥数保留原有表单和业务行为。
- 每次选择一份母卷分析；将母卷标题、学科、覆盖范围和当前学生年级展示给用户。默认当前学生年级为目标，不额外要求选择教材。
- 默认沿用母卷题型、分区与可作答子题量；阅读材料的一个题组与其多个子题应明确区分。允许按分区/题型调整数量，确认前展示最终可作答题总数。
- 母卷没有标准答案也可分析出题；原创题必须有独立参考答案和解析，不依赖源卷是否附答案。
- 生成结果进入统一学习任务索引，在智慧课堂“模拟考试”和学习资料“生成的学习资料”中可访问，复用已确认的删除、筛选、完成状态、作答回顾和A4试卷/答案卷能力。
- 生成时使用现有进度和5分钟页面锁定规则。页面解锁不等于后端任务已取消，不得因此自动重复建卷。

### 2.3 非目标

2026-10-22 范围变更（用户已确认，BR-MM-013）：原卷绘图子题改成相同知识点的原创文字问答，保留默认题量与年级难度；摘要标注“问答题（原绘图题）”，以现有文字作答控件完成。混合题组仅转换绘图子题。不新增画板或上传作答，不修改已生成试卷/历史作答；材料缺失仍阻断。该条覆盖此前“真正绘图一律不支持”的范围，其他题型规则保持。

- 不恢复学习中心、视频、系统评分或模型批改。
- 不修改原教材/试卷文件，不生成或迁移母卷原题全文副本，不清理历史资料。
- 不把“同类型”解释成原题换数字，不引入外部教材、试卷或题库。
- 不扩展为多母卷混编、任意年级覆盖或一键补齐原卷缺页。
- 本轮MVP不自动扩展到作业/扫描记录库；如需要从该库选母卷，作为另一个明确来源补充契约。

## 3. 方案与验收草案

### 3.1 已确认产品规则

| 场景 | 预期行为 |
| --- | --- |
| 已知试卷分类/标签 | 进入“模拟考试→母卷出题”的候选，教材章节列表排除；标题仅作为提示证据，不单靠“期末”等词硬判资料类型。 |
| 无目录但正文完整 | 正常分析，不要求章节，也不伪造章节。 |
| 正文未解析/解析失败 | 禁止生成，说明“母卷正文尚未可用”，引导回学习资料处理。 |
| 结构识别成功 | 展示题型/分区/子题量、知识点、覆盖范围；用户确认后才生成。 |
| 题型未知或结构不确定 | 指出具体不确定项，不把所有题压成统一选择/填空/问答后声称等同母卷。 |
| 完整笔试版但缺听力 | 明确“仅笔试范围”；不自动生成缺失的原卷听力部分。若正文中残留缺材料的听力题，必须说明并由用户确认范围，不静默漏题。 |
| 阅读/图片题缺少必须材料 | 禁止将该来源误判为完整；提示缺图/缺阅读材料，不能生成看似完成的整卷。 |
| 母卷年级与当前学生不同 | 显示两者。优先在源卷知识范围内按学生年级适配；无法合理适配的知识点需明确阻断或申请调整范围，不能偷偷改目标年级或补外部教材。 |
| 题量大于当前旧蓝图 | 仍按用户确认数量生成；未满足完整性则失败，不回退固定9/10题；有界分段策略由Gate 4确认。 |
| 失败/超时/刷新 | 保留可识别的任务状态、错误提示和幂等边界；不得保存可见的半成品测试。 |
| 提交完成 | 显示已完成，逐题连续展示题目、学生答案、参考答案、解析，可标记需巩固，不显示对错或成绩。 |

### 3.2 验收草案

| ID | 输入/操作 | 通过条件 |
| --- | --- | --- |
| AC-SP-001 | 已解析的无目录四年级英语期末母卷 | 三个同级入口中的“模拟考试”可进入母卷模式选择并分析，无章节控件/请求；教材入口不出现该试卷；可切换奥数模式。 |
| AC-SP-002 | 母卷含三个分区、多个题组及子题 | 摘要保留分区和题型，计数以可作答子题为准，默认题量与母卷一致。 |
| AC-SP-003 | 调整某分区题量后生成 | 确认页和输出题量完全一致；其他分区不被静默修改。 |
| AC-SP-004 | 五年级母卷+四年级学生档案 | 显示源卷/目标年级差异；目标以当前学生档案为准，任务保留生成时年级快照，刷新不随档案变化重写旧卷。 |
| AC-SP-005 | 无标准答案但正文完整 | 可生成含独立参考答案、解析的新题；没有缺答案阻断。 |
| AC-SP-006 | 缺正文、缺图、缺听力原文、识别不确定 | 分别出现明确说明，不伪造目录/内容、不直接生成伪完整整卷。仅笔试范围必须可见。 |
| AC-SP-007 | 含阅读材料/组合题的原创测试 | 材料与题目关联完整，网页作答和A4 PDF都可独立理解和作答，答案卷与题号对应。 |
| AC-SP-008 | 截断、错误JSON、题量不符、供应商错误 | 原有学习内容保持不变，无半成品卷；任务进入失败或明确待处理状态，可理解错误并受控重试。 |
| AC-SP-009 | 成功生成、提交、刷新、列表筛选、删除生成资料 | 智慧课堂/生成资料列表一致；完成状态正确、历史作答可回顾；删除沿用既有契约并保留上传母卷。 |
| AC-SP-010 | 教材/奥数/错题既有关键路径 | 教材/错题入口保持；奥数能力可从“模拟考试→奥数模拟”访问；来源边界、生成结构、作答回顾和PDF不退化，模型批改不被重新触发。 |

## 4. 风险

- 默认沿用母卷题量和阅读/听力等题型，超过现有固定蓝图能力；需要真实长卷验收，不只测试10题示例。
- 学科/年级元数据可能不完整；当前档案也可能回退为一年级。若年级证据不足，应要求用户先确认档案，不能把系统兜底当作事实。
- “母卷缺失”与“完整笔试版”必须区分；仅笔试版可以作为明确范围的母卷，不得声称其包含完整听力。
- 模型可能忽略题量、原创性或年级约束；提示词不能替代结构校验、完整性验证和抽样内容审核。
