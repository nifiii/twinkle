# 学生学习内容：任务分解（Gate 5）

状态：已确认（2026-08-04）

## 1. 背景

新版学生自学课件和统一错题本将在同一服务上替换旧学习小助手能力。上线前需要清空旧派生学习数据，但必须保留上传教材、上传试卷和非错题扫描资料。数据清理、生成、读取和页面展示必须分任务验收，避免把一次不可逆删除与普通功能改动混在一起。

## 2. 目标

交付可验证的新版学习闭环：教材章节生成学生自学课件和配套测验；学习资料显示统一错题本；旧学习助手资料在备份、清单和人工批准后清空且不再可访问。

## 3. 方案

### 里程碑 M1：可审计的数据清理

### T-001 清理清单与备份（dry-run）

Outcome：

- 运维人员可运行非写入命令，获得数据库备份、错题专属文件备份、SHA-256 和待删/保留清单。
- 清单明确区分“删除的学习助手派生数据”和“保留的上传教材、上传试卷、非错题扫描资料”。

Inputs：

- BR-SSC-011、BR-SSC-012；AC-SLC-005、AC-SLC-005a。
- [技术设计](../architecture/2026-08-04-student-learning-content-technical-design.md) 3.5、3.7；[API 契约](../architecture/2026-08-04-student-learning-content-api-contract.md) CLI 契约。

Scope：

- `backend/src/scripts/learningAssistantReset.ts` 及其直接测试文件。
- 读取 `databaseService`、`learningDomain`、`fileStorage` 的既有路径约定；新增本任务的运维说明。

Non-goals：

- 不删除数据库行或文件。
- 不改变任一 API、前端、课件生成或错题本行为。
- 不执行生产环境命令。

Acceptance：

- `--dry-run` 创建时间戳目录，含数据库副本、文件备份、SHA-256、`manifest.json`。
- 测试种子同时含 `books`、`exam_paper`、非错题扫描项、错题、课件、测验、模拟考试、作答和成绩；manifest 只将约定删除集合列为候选。
- 任何保留文件被错误纳入、路径越界或无法解析的错题文件路径出现时，以 `blocked` 和非零退出结束，原始数据库/文件哈希不变；被保留资料引用的错题文件必须列为保留而非阻断。

Freedom：

- 可选择 manifest 的内部 JSON 字段顺序、测试夹具和路径遍历实现。
- 不得改变删除集合、保留白名单、备份位置约束或命令显式 `--apply` 规则。

Dependencies：无。

### T-002 受控应用、回滚材料与生产运行手册

Outcome：

- 运维人员只能将与 dry-run 完全一致、无阻断项的清单用于 `--apply`；成功后旧派生数据与专属文件被清除，保留资料可证明未变。
- 提供停止服务、执行、校验、恢复和故障退出步骤。

Inputs：

- T-001；BR-SSC-011、BR-SSC-012；AC-SLC-005a、AC-SLC-005b；Gate 4 的恢复契约。

Scope：

- `backend/src/scripts/learningAssistantReset.ts`、其测试、`retired_learning_content` 下线索引初始化/写入边界、`docs/plans/` 下的运行手册。
- 仅处理删除集合中的表、链接、事件和错题专属文件。

Non-goals：

- 不删除 `books`、非错题 `scanned_items`、上传源文件或 `external_resources`。
- 不在实现任务中执行生产 `--apply`，也不部署新镜像。

Acceptance：

- `--apply --manifest <path>` 重新计算集合；集合、保留资料 ID/计数/SHA-256 任一不一致即无写入退出。
- 仅 `wrong_problem` 的固定历史前缀 `/opt/hl-os/data/` 可映射为当前数据卷内同相对路径；映射文件缺失时 manifest 记为 `missing` 且 apply 不移动文件，其他卷外路径仍必须阻断。
- 集成测试验证课件、测验、模拟考试、作答、成绩、错题、任务和专属文件删除；对应下线索引只保留 `ownerId + entityType + entityId + retiredAt`；上传教材、上传试卷、非错题扫描项和源文件保持不变。
- 待删错题专属文件先原子暂存到同一数据卷的备份目录；数据库事务失败时必须移回原路径，成功后只在备份目录保留恢复副本。
- 运行手册包含生产前停服务/关闭入口、dry-run 人工核对、apply 后验证、恢复条件和回滚命令。

Freedom：

- 可选择 SQL 语句组织、事务封装与结果摘要格式。
- 不得通过级联删除、模糊文件名、标题匹配或跳过 manifest 一致性验证扩大范围。

Dependencies：T-001。

### 里程碑 M2：学生自学闭环

### T-003 学生课件与配套测验生成服务

Outcome：

- 学生选择已解析教材章节后，得到结构合格的自学课件和同章节原创随堂测验；任一生成失败不会留下半成品。

Inputs：

- BR-SSC-001 至 BR-SSC-010；AC-SLC-001 至 AC-SLC-004；技术设计 3.3、3.4；API 契约 `POST /api/learning-tasks`。

Scope：

- `backend/src/services/textbookTaskService.ts` 或直接生成服务、结构校验模块、学习任务服务的必要边界、对应单元/集成测试。

Non-goals：

- 不改变奥数模拟考试、上传教材解析、自动批改、PDF 或既有题目评分规则。
- 不读取或转换已清理的历史课件。

Acceptance：

- 四年级数学、英语、语文、科学真实章节夹具均能生成 6 至 10 步学生自学结构和 `primary + practice` 链接。
- 教师话术、缺少必需步骤、章节正文不足、模型失败均使任务失败且无课件/测验半成品。
- 同一 `ownerId + requestKey` 不重复生成。

Freedom：

- 可选择模型提示词、校验器拆分、事务辅助函数和测试替身。
- 不得放宽章节来源、结构不变量、原创约束或测验自动关联规则。

Dependencies：T-002 的数据清理契约；不依赖生产 apply 完成。

### T-004 学习任务读取与旧内容下线语义

Outcome：

- 新任务按学生自学结构读取；旧学习助手 ID 不能恢复旧正文、测验、成绩或错题，只返回稳定下线状态。

Inputs：

- BR-SSC-011；AC-SLC-005b；技术设计 3.3、3.5；API 契约 `GET /api/learning-tasks/:id`、`GET /api/classroom/:id`。

Scope：

- `backend/src/routes/learningTasks.ts`、课堂读取路由/查询服务、`retired_learning_content` 只读查询和对应路由测试。

Non-goals：

- 不新增历史重定向、恢复 API 或删除 HTTP API。
- 不影响上传教材与上传试卷的读取接口。

Acceptance：

- 新章节任务返回结构化课件及配套测验链接。
- 已清理旧助手任务/实体返回 `410 learning_content_retired`；普通未知 ID 保持 `404 task_not_found`。
- 上传教材、上传试卷读取回归测试通过。

Freedom：

- 可选择错误映射辅助函数和实体读取内部组织。
- 不得让客户端依 JSON 形状读取旧数据，或把 `410` 降级为 `404/500`。

Dependencies：T-002、T-003。

### T-005 学生自学课件前端阅读与创建

Outcome：

- 学生可在学习小助手选择教材章节，创建并阅读新课件、完成非计分自检、进入同章节随堂测验；旧地址显示下线状态。

Inputs：

- US-SLC-001 至 US-SLC-003、US-SLC-006；AC-SLC-001 至 AC-SLC-004、AC-SLC-005b、AC-SLC-006。
- Gate 3 用户流程、页面状态、UI/UX 与前端设计；T-003、T-004 API 行为。

Scope：

- 学习小助手、智慧课堂任务详情及其直接样式/组件/前端测试。

Non-goals：

- 不新增顶级路由、独立设计主题、模型调用或客户端教材解析。
- 不显示旧学习助手缓存、详情或重定向。

Acceptance：

- 章节选择状态、生成/失败/重试、步骤进度、自检反馈、测验入口和下线状态符合 Gate 3 页面状态。
- 390px、768px、1440px 无文字/控件重叠；键盘可到达所有操作；截图符合既有学习资料和智慧课堂页面语言。
- `410 learning_content_retired` 只显示“该学习内容已下线”和返回智慧课堂。

Freedom：

- 可选择组件拆分、局部状态和既有图标组合。
- 不得修改已确认的路由、视觉令牌、非计分语义或下线状态文案含义。

Dependencies：T-003、T-004。

### 里程碑 M3：统一错题本

### T-006 统一错题本只读查询 API

Outcome：

- 新服务产生的扫描错题和课堂错题可通过一个来源可识别、支持部分成功的只读 API 查询。

Inputs：

- BR-UWB-001 至 BR-UWB-007；AC-UWB-001 至 AC-UWB-006；技术设计 3.6；API 契约 `GET /api/wrong-book`。

Scope：

- 新/既有错题查询服务、路由注册、服务与路由测试。

Non-goals：

- 不复制课堂错题到扫描表，不改旧错题统计、评分或复核。
- 不在 API 中执行 reset 或回填旧数据。

Acceptance：

- 两类来源按来源、学科、时间、关键词、分页筛选；课堂来源只返回可用的已完成错题。
- 单来源失败仍为 `200` 部分成功；双来源失败为契约指定错误；课堂条目不可编辑/删除。
- 查询不产生任意数据库写入。

Freedom：

- 可选择游标编码、内部查询拆分和错误隔离方式。
- 不得更改标准化 ID、来源引用、权限能力字段或写入边界。

Dependencies：T-002。

### T-007 统一错题本前端

Outcome：

- 学习资料错题本可浏览、筛选和区分新产生的拍题归档/课堂作答错题，并跳转到正确的原始详情。

Inputs：

- US-SLC-004、US-SLC-005；AC-UWB-001 至 AC-UWB-006；Gate 3 设计；T-006 API。

Scope：

- `#resources/capture` 对应组件、局部样式、前端测试与视觉验收脚本。

Non-goals：

- 不改变上传试卷列表、扫描错题编辑删除逻辑或创建学习任务逻辑。
- 不在浏览器合并原始表数据。

Acceptance：

- 全部/拍题归档/课堂作答分段筛选、学科/时间/关键词、空、部分失败和双失败状态符合 Gate 3。
- 课堂条目只能查看测验详情；扫描条目保留既有查看/删除入口，本期不新增持久化编辑入口。
- 三视口和键盘焦点检查通过。

Freedom：

- 可选择请求缓存、取消机制和组件层级。
- 不得改写来源标签、详情跳转契约、只读能力或现有视觉语言。

Dependencies：T-006。

### 里程碑 M4：发布验证

### T-008 本地回归、视觉验证与生产前检查

Outcome：

- 发布候选镜像具备代码、接口、浏览器和清理 dry-run 证据，生产执行条件清晰。

Inputs：

- T-001 至 T-007；全部 AC-SLC/AC-UWB；Gate 3 视觉验收；Gate 4 发布与恢复规则。

Scope：

- 现有测试配置、Playwright 证据目录、发布运行手册与环境变量说明。

Non-goals：

- 不执行生产 `--apply`、不变更生产教材/试卷、不擅自推送或部署。

Acceptance：

- 后端单元/集成测试、前端构建、三视口浏览器路径和关键键盘路径通过。
- 本地 dry-run 生成可审计 manifest；保留资料校验通过。
- 评审分别记录 Spec、UI/UX 和代码质量结论，且无阻断项。

Freedom：

- 可选择现有测试命令、夹具和截图命名。
- 不得跳过清理 dry-run、保留资料校验、API 合约验证或三视口检查。

Dependencies：T-001、T-002、T-003、T-004、T-005、T-006、T-007。

### T-009 经人工授权的生产清理与上线

Outcome：

- 在人工核对清单和单次生产写入授权后，生产旧学习助手派生数据被清空，新版服务可用，上传教材/试卷仍可访问。

Inputs：

- T-008 的发布证据；T-002 运行手册；经人工确认的生产 dry-run manifest；本次单独的 `--apply` 授权。

Scope：

- 仅生产服务维护窗口、已部署镜像、受控数据卷和 T-002 定义的 CLI。

Non-goals：

- 不执行范围外数据库操作，不删除教材/上传试卷，不修改模型配置，不在未授权时执行 `--apply`。

Acceptance：

- 服务停止/创建入口关闭后执行 approved manifest；退出成功。
- 删除/保留计数、源文件 SHA-256、上传教材与上传试卷读取、旧内容 `410`、新课件创建和配套测验路径均通过。
- 备份和 manifest 路径、版本、执行人、时间和验证结果记录在运行日志。

Freedom：

- 可选择维护窗口内的健康检查顺序和日志采集方式。
- 不得绕过单次 `--apply` 授权、manifest 一致性校验、备份校验或恢复条件。

Dependencies：T-008；生产运行需单独用户授权。

## 4. 风险

| 风险 | 控制 |
| --- | --- |
| 误删除上传资料 | T-001/T-002 以表级白名单、文件引用和 SHA-256 证明保留范围。 |
| 删除脚本与新版功能互相干扰 | M1 完成后才允许 M2/M3 验收；生产清理由 T-009 单独授权。 |
| 历史地址泄漏旧内容 | T-004/T-005 固化 `410 learning_content_retired` 和无重定向状态。 |
| 错题本重新污染旧统计 | T-006/T-007 只读聚合，不做迁移/复制。 |
