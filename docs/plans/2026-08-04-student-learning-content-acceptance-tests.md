# 学生学习内容：验收用例（Gate 3）

状态：已确认；新版上线前学习助手派生数据清理验收已纳入

## 1. 背景

本用例覆盖新生成的学生自学课件与学习资料统一错题本，不以覆盖历史数据为目标。

## 2. 目标

在编码前固定可观察的学生学习结果、数据边界和异常行为。

## 3. 方案

| ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-SLC-001 | 四年级数学教材存在“角的度量”有效章节正文。 | 学生生成课件。 | 新任务标记学生自学模式，包含目标、分步讲解、示例、自检、易错提醒、小结，且不含教师备课话术。 |
| AC-SLC-002 | 四年级英语、语文、科学各有有效章节。 | 分别生成课件。 | 每科内容含对应学科示例，且所有内容锚定所选章节。 |
| AC-SLC-003 | 学生正在阅读新课件。 | 跳过即时自检并点击随堂测验。 | 显示建议完成自检但允许进入同章节测验；自检不生成成绩记录。 |
| AC-SLC-004 | 模型返回缺少必需学习步骤或出现教师授课指令。 | 系统校验生成结果。 | 任务失败且不保存为可学习课件；学生保留章节选择并可重试。 |
| AC-SLC-005 | 同一数据库含上传教材、上传试卷、错题、旧课件、随堂测验、模拟考试、作答、成绩与学习任务。 | 执行删除迁移 dry-run。 | 生成数据库和专属文件的可校验备份及清单；清单列出全部派生实体和错题文件，明确排除 `books`、`scanned_items.type='exam_paper'`、其他非错题扫描资料和保留文件。 |
| AC-SLC-005a | dry-run 清单发现待删错题文件仍被保留资料引用、未知数据关联或保留资料校验失败。 | 尝试执行 `--apply`。 | 命令失败且不写数据库或文件系统；阻断清单列出引用、关联或校验原因。 |
| AC-SLC-005b | AC-SLC-005 的清单无阻断项。 | 执行 `--apply` 后重新读取数据与文件清单。 | 旧课件、测验、模拟考试、作答、成绩、错题、任务及专属文件不存在；上传教材、上传试卷和其他非错题扫描资料及源文件计数与 SHA-256 不变；旧学习内容地址显示下线状态，不提供正文、成绩、错题或重定向。 |
| AC-SLC-005c | 一条 `wrong_problem.mdPath` 使用固定旧前缀 `/opt/hl-os/data/`，其映射到当前数据卷后的文件不存在；另一条错题使用任意未知卷外路径。 | 执行 dry-run，并仅对前一种场景执行 apply。 | 固定旧前缀条目列入 `delete.files.missing` 且不阻断，apply 不暂存该文件但删除对应派生记录；未知卷外路径保持 `unsafe_file_path` 阻断且不写数据。 |
| AC-UWB-001 | 当前学生有一条扫描错题和一条已完成课堂测验错题。 | 打开学习资料 → 错题本。 | 两条均展示，分别带“拍题归档”“课堂作答”文本标签。 |
| AC-UWB-002 | 统一错题本显示两类错题。 | 选择“课堂作答”、数学、最近 7 天。 | 仅显示满足全部条件的课堂数学错题。 |
| AC-UWB-003 | 用户点击课堂作答错题。 | 选择查看详情。 | 进入该题的原测验成绩/逐题详情，且无编辑、删除扫描记录操作。 |
| AC-UWB-004 | 用户点击拍题归档错题。 | 选择查看错题或删除。 | 保留既有错题详情和删除行为；本期不新增持久化编辑入口。 |
| AC-UWB-005 | 课堂错题来源接口失败、扫描来源正常。 | 打开错题本。 | 扫描错题仍显示；课堂来源显示可重试错误状态。 |
| AC-UWB-006 | 同题同时有扫描和课堂来源。 | 打开全部来源。 | 显示两条带来源区分的记录；不复制课堂数据到扫描错题表。 |
| AC-SLC-006 | 390px、768px、1440px 视口。 | 完成课件阅读与错题本筛选。 | 文本、标签、筛选与主操作不重叠；键盘能访问全部操作。 |

示例数据：四年级数学“角的度量”、英语“Unit 1”、语文单元阅读、科学观察章节；一条 `scanned_item` 错题与一条 `quiz_result` 错题，均属 `child_1`。

## 4. 风险

- 验收不得把课堂错题是否进入旧扫描统计作为 UI 判断；应直接检查其来源引用与数据库无迁移写入。
