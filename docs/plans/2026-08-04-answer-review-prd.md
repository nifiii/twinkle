# 作答回顾与需巩固标记 PRD（Gate 2）

状态：已确认（2026-08-04）

上游依据：`docs/requirements/2026-08-04-answer-review-business-requirements.md`。

## 1. 背景

学生完成练习后的重点是自主核对和后续巩固，不是让系统以考试口径替代教师判卷。现有自动批改、分数、改判和成绩趋势须退出学习流程。

## 2. 目标

1. 作答一经提交即可进入完整作答回顾，不等待模型。
2. 学生能够逐题对照自己的答案、参考答案和解析。
3. 只有主动标记“需巩固”的题进入课堂错题本与后续错题学习。
4. 历史评分数据被安全清除，上传资料与教师批注不受影响。

## 3. 方案

### 3.1 MVP 范围

| 领域 | 必须能力 |
| --- | --- |
| 提交 | 课堂测验及试卷作答提交后同步保存题目快照和答案，无模型批改任务。 |
| 回顾详情 | 每题固定展示题干、学生答案、参考答案、解析和“需巩固”开关。 |
| 历史 | 历史已完成记录统一以作答回顾打开；所有评分展示退出。 |
| 错题本 | 课堂来源仅返回主动标记需巩固的题目，支持取消标记后即时消失。 |
| 看板 | 移除掌握率、成绩趋势及所有评分依赖数据。 |
| 清理 | 备份后删除既有评分字段和评分专属表记录，保留作答可回顾内容。 |

### 3.2 用户故事

| ID | 用户故事 | 优先级 |
| --- | --- | --- |
| US-AR-001 | 作为学生，我交卷后立刻能在同一题下对照题目、我的答案、参考答案和解析。 | Must |
| US-AR-002 | 作为学生，我能对需要再练的题点“需巩固”，而不是被系统判定对错。 | Must |
| US-AR-003 | 作为家长，我看到历史作答回顾而不是分数、批改或改判操作。 | Must |
| US-AR-004 | 作为学生，我在错题本只看到自己/家长标记为需巩固的课堂题目及原有教师批注错题。 | Must |
| US-AR-005 | 作为家长，我知道上传试卷的教师批注没有因该改造被删除。 | Must |

### 3.3 不可变规则

- 回顾展示的题目与学生答案必须来自同一次已提交作答快照，不能重新生成或用当前题库覆盖。
- 参考答案与解析来自该作答快照；缺失时明确呈现缺失，不能调用模型补写。
- 标记只由当前 `ownerId` 的作答记录写入；不构成跨家庭安全边界以外的访问授权。
- 历史评分清理不触碰 `books`、`assessment_papers`、`scanned_items`、上传源文件、教师批注及非评分学习任务。

### 3.4 非目标

- 不保留任何自动评分、评分模型调用、分数和成绩趋势兼容读取。
- 不提供人工打分、复核、改判或教师判卷替代。
- 不将“需巩固”自动同步为上传扫描错题。

## 4. 风险

- 这是数据删除变更，生产执行必须采用 manifest、备份与单次授权。
- 旧记录可能缺少可展示的题目快照；此类记录保留时间与归属，但无法完整回顾时展示稳定说明，不将其转为评分页面。
