# 1. 背景

本计划把已有文字母卷原创试卷扩展为可验证的多模态母卷流程。

# 2. 目标

交付视觉证据契约、多选题端到端支持、听力原文复用、简单图形资源和回归验证。

# 3. 方案

后端新增 `sourcePaperVisionService`，通过安全的教材/试卷原始文件路径渲染页面并调用视觉模型；`assessmentPaperService` 将证据摘要作为生成上下文并扩展 `multi_choice`；前端、作答快照、PDF 导出保持同一题型契约。

# 4. 风险

Vision 输出可能不完整，必须由结构化校验判定；旧蓝图只允许文字题，迁移时保持 schemaVersion 向后兼容。
