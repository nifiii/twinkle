# 母卷绘图题转文字问答：实施与生产验证

## 1. 背景

番禺四下英语母卷共 5 页，第 31 题明确要求学生绘图并配话。原契约将学生自由绘图列为非目标，因此此前阻断并非图片识别错误。用户于 2026-10-22 确认：这种绘图题统一改成对应问答题。变更归属需求范围（Gate 1/2），已同步 PRD、设计、API、技术设计、AC-MM-014 与 T-MM-005，再继续实施。

独立代码 bug 为错误原因被覆盖、固定证据触发无效文本模型重试、终态母卷失败任务进入可学习列表。对应修复不改变真正缺失材料的阻断门槛。

## 2. 目标

原绘图子题转为相同知识点和适龄难度的原创文字问答，默认题量不变；混合分区中非绘图题保持类型。学生使用既有文字作答、回顾与 PDF，无需新增画板或上传答案图片。

## 3. 方案与验证

- 视觉证据保留原卷 `requiresDrawing`，不再将绘图需求伪造为缺失项；真实缺页、模糊或缺图照常阻断。
- 摘要归一为 `essay`，显示“问答题（原绘图题）”，持久化转换标记和文字考查目标；创建任务复核同一契约。
- 生成只消费当前分区结构和知识点。转换题仍要求学生绘图时拒绝发布，无半卷；既有原创性、配图、材料和题量校验保留。
- 远程 Node 20 隔离容器：编译成功，全量测试 162/162 通过，不读取生产配置或数据。覆盖混合题型、题数、文字提交/回顾、残缺资料零文本模型调用、绘图指令拒绝及供应商错误隐藏。
- 本机前端 TypeScript/Vite 构建成功；大型 JS chunk 提示是既有构建警告。
- GitNexus 单符号影响为 LOW；汇总变更因分析/创建链及文档数量标为 HIGH，已逐项复核为本任务范围。
- 生产验证尚未完成；不得用隔离测试替代真实母卷生成成功证据。

## 4. 风险与恢复

真实模型仍可能遗漏子题或产生无法作答的材料，必须以实际番禺母卷生成、网页阅读和 PDF 验证闭环。失败分析需重新发起，不重写旧成功卷或历史作答，不删除原始教材/试卷/失败记录。发布保留旧镜像和回滚容器，不涉及数据库 schema 迁移。
