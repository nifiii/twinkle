# 当前年级与试卷分类缺陷验证记录

## 1. 背景

用户授权按建议修复。代码基线为 answer-review 工作树 c0526ea，本次变更尚未推送或部署。两项偏差确认属于代码实现 bug；实现方案见[修复任务与契约](../plans/2026-10-19-profile-grade-material-classification-fix.md)。

## 2. 目标

当前年级显式保存后真实持久化；明确试卷分类在教材入口排除、母卷入口可选；保持年度升级、奥数、历史作答和源资料不变。

## 3. 方案与结果

### 根因及最小复现

| 问题 | 修改前证据 | 修改 |
| --- | --- | --- |
| 四年级保存后仍为五年级 | 临时 SQLite 内基准 4/2026-07，时钟 2026-10，PATCH 4 返回 gradeNum=5；旧代码仅在基准数字变化时重设锚点 | 显式传年级总是重锚当前中国月份；省略字段不变，null 清除。编辑初值使用有效 gradeNum。 |
| 自动推算切换无效/失败仍退出 | undefined 在 JSON 中省略，无法清除旧基准；表单未等待异步保存 | 清除明确传 null；等待成功才关闭，失败原位提示，保存中禁编辑/重复提交。 |
| 考试真题仍是教材候选 | 原分类函数对 category=考试真题、tags=期中测试/期中真题返回 false；生产只读样本及真实候选接口完全吻合 | 补识别明确标签，继续复用共享分类函数、排除奥数，不改数据库分类或依赖标题。 |

修改前新回归测试失败；修复后全部通过。关于“缓存或元数据不同步”的早期猜测无已验证证据，不作为本次修复依据。

### 使用与上线验证

1. 前后端需一并部署；无表结构变更、不执行数据迁移。未自动重设任何生产档案。
2. 部署后刷新页面，在编辑资料中重新选择实际当前年级“四年级”并保存；刷新再打开确认仍为四年级。新分析读取更新后的档案；旧卷年级快照保持。
3. 教材章节入口确认不再包含上述试卷；模拟考试→母卷出题确认五上英语及四下语文也可选；奥数模式仍可选择竞赛资料。
4. 已基于错误年级产生的分析应重新分析，不能复用旧年级快照。
5. 原卷缺图/图画作答仍会阻断，这是已确认的文字母卷 MVP 边界。应先核对原 PDF 和解析产物，再单独确认图题扩展；不能仅删除校验或把不同年级直接当作材料缺失。
