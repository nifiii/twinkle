```powershell

$env:DATA_DIR = Join-Path (Get-Location) '../tmp/ark-upgrade-tests'
npm test

node scripts/verify-ark-models.mjs --env-file D:/devops/twinkle/.env --output ../tmp/ark-compatibility.json
```

前端复验依赖工作树能够解析现有前端依赖。本机本轮使用主目录已安装依赖的绝对入口执行`tsc --noEmit`及`vite build`，未新增包或修改lock文件。Vite构建存在已有的单包超过500KB提示，未阻断构建。
