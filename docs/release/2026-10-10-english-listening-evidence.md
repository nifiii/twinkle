# 英语听力提前看题与固定五题：验证与发布说明

## 1. 背景

生产听力包 `6de38534-a7f8-4b02-9d2c-127e4205a6e1` 经只读 API 与浏览器检查，保存 3 道题，年级档为 `g3_4`、`questionRange=[3,3]`；首次播放未完成时 `questionsUnlocked=false`，前端据此隐藏题目。两个现象均由原已确认规则导致，属于本轮明确需求变更，不属于代码实现 bug。

工作基线：`origin/master` 与本地 HEAD 均为 `c11df8ca1e6a9d17813f9265123cf44ee8f3e758`；实现位置为 `D:/devops/twinkle/.worktrees/answer-review`。

## 2. 目标

- 学习包加载后立即显示题干、选项和实际题数，可以先选择答案。
- 新生成的 1-2、3-4、5-6 年级听力统一为 5 题；数量不符拒绝保存。
- 原文仍在第一次完整播放后开放，参考答案、解析与评分点仍在提交后展示；提交仍要求完整听过。
- 历史包保持原始内容、题数和答案快照；无数据库迁移。

## 3. 方案

### 实现边界

仅修改 `LearningPackage` 的题目展示与提交提示，以及 `learningPackageService` 的新包题数约束和 `questionsUnlocked` 响应。现有提示词与保存前校验复用同一年级档；TTS 供应商、缓存、语速适配器和其他学习内容不变。同步需求、PRD、流程、前端设计、API、技术设计、验收与任务分解。

### 发布与使用

本报告记录提交前验证结果，不代表生产部署完成。发布时同时更新前端与后端。发布后打开旧链接即可先看原有 3 道题；要获得 5 道题，需要从学习小助手创建新的听力任务。对新内容的模型与真实音频端到端结果，本轮未进行验证，不能将夹具通过视为生产生成通过。

上线后检查：旧链接播放前可查看题目，原文与提交尚未开放；创建新包后确认实际 5 题；听完后提交与刷新均显示原答案快照。

## 4. 风险

- 旧包不会自动补题，避免改变已生成内容及历史作答关系。
- 增加题量可能使模型输出校验失败；沿用现有失败语义，不保存不合格内容，不拼接题目凑数。
- 浏览器验证模拟音频结束与失败，证明状态流转，不证明供应商音频质量或实际语速。
- 回滚部署到基线版本即可恢复旧显示和新生成数量规则；无需回滚数据库。已生成的 5 题包仍按存储内容读取。
