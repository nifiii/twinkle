## 4. 风险

- 任务过期阈值依赖模型调用上限；当前各调用单次超时为两分钟，试卷解析失败可重试一次，仍低于五分钟收敛阈值。
- 历史模拟考试不重试，防止用默认参数替换学生原先选择的题型与难度。
- GitNexus MCP 当前未挂载 `twinkle`，本地 CLI 受 Windows 用户目录 `realpath` 权限阻断。本次以源码调用点、后端测试、前端构建和生产接口/浏览器证据替代；该工具环境问题需单独修复，不影响生产结论。
