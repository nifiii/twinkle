# 统一错题本：业务需求基线（Gate 1）

状态：已确认

## 1. 背景

学习小助手的错题讲解与测验已聚合拍题归档错题和课堂作答错题，但学习资料的“错题本”只显示拍题归档错题。学生会在两个页面看到不同范围的错题，且无法从学习资料回看课堂作答中的错误。

## 2. 目标

学习资料的错题本成为统一的错题发现与回看入口，展示当前学生的拍题归档错题和课堂作答错题；两类记录保留自己的来源、详情与统计语义。

## 3. 方案

### 3.1 业务规则

| ID | 规则 |
| --- | --- |
| BR-UWB-001 | 学习资料 → 错题本必须聚合当前学生的拍题归档错题和已完成课堂测验中的已判错题目。 |
| BR-UWB-002 | 每条错题必须显示来源标签：“拍题归档”或“课堂作答”；来源不能只由颜色区分。 |
| BR-UWB-003 | 拍题归档错题保持现有查看、删除和错题讲解关联能力；课堂作答错题只读展示，并进入原测验成绩/逐题详情。 |
| BR-UWB-004 | 课堂作答错题不得复制、迁移或伪装为 `scanned_items`；不得写入既有 `wrong_problem_quiz_links` 或改变旧扫描错题统计。 |
| BR-UWB-005 | 学科、时间和关键词筛选必须同时应用于两类来源；无匹配结果时说明当前筛选条件。 |
| BR-UWB-006 | 学习小助手与学习资料对同一学生、同一筛选学科的错题数量可因“是否需要参考答案”等生成资格不同而不同，但必须明确展示各自的来源与范围，不能静默漏项。 |
| BR-UWB-007 | 学习资料的统一错题本只读聚合不创建学习任务、不触发模型生成、不修改课堂测验结果或自动批改分数。 |

### 3.2 输入与输出

| 类别 | 内容 |
| --- | --- |
| 输入 | 当前学生 `ownerId`、扫描归档错题、已完成课堂测验的逐题批改结果、筛选条件。 |
| 输出 | 可按来源识别的统一错题列表，以及每条记录的安全详情入口。 |
| 数据边界 | 扫描错题为 `scanned_item` 引用；课堂错题为 `quiz_result` 引用；两类引用不可互相转换。 |

### 3.3 共享术语

| 术语 | 定义 | 不使用的含义 |
| --- | --- | --- |
| 统一错题本 | 学习资料内聚合展示两类错题的只读视图。 | 把课堂错题复制成拍题记录的新数据仓库。 |
| 拍题归档错题 | 从用户上传图片/试卷识别并归档的错题。 | 课堂测验作答结果。 |
| 课堂作答错题 | 已完成测验中自动批改或人工改判为错误的题目。 | 可编辑的扫描错题。 |
| 来源引用 | 能回到原始扫描记录或原始测验结果的稳定标识。 | 用题干文本猜测或合并两条记录。 |

### 3.4 边界与异常

- 批改中、批改失败或尚未完成的课堂测验不进入统一错题本。
- 课堂题干、正确答案或批改结果缺失时不展示为可学习错题，避免误导；页面可显示已跳过数量与原因。
- 同一道题同时存在扫描归档和课堂作答两种来源时分别展示，不擅自去重，因为来源、作答和诊断记录不同。
- 用户切换学生档案后必须重新读取两类来源，不能保留上一个学生的列表。

## 4. 风险

| 风险 | 控制方向 |
| --- | --- |
| 复制课堂错题污染旧统计 | 只读聚合，保留 `quiz_result` 原始引用。 |
| 统一列表产生重复感 | 显示来源、时间和原始任务；不做无依据文本去重。 |
| 课堂结果权限/归属混乱 | 所有查询按当前 `ownerId` 过滤；详情进入原结果页。 |
| 读取两类来源失败 | 页面分别报告“拍题归档”或“课堂作答”加载失败，已成功来源仍可浏览。 |
