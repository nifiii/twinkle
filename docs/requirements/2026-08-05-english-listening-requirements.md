# 英语听力适龄与复听规则变更（Gate 1）

状态：待确认（变更控制）

上游基线：`2026-07-28-learning-assistant-business-requirements.md` 的 BR-009、BR-019。

## 1. 背景

现有英语听力只按章节正文提示模型生成，且以两次完整播放限制控制作答。四年级学生实际使用时，音频语速偏快，听完后无法在作答前回看文本，也不能按自己的节奏重复听。

## 2. 目标

让 1 至 6 年级普通小学学生能围绕自己上传教材的章节完成原创英语听力练习；难度和建议语速随教材年级变化，学生可不限次数复听，首播完成后可展开文本辅助理解。

## 3. 方案

| ID | 规则 |
| --- | --- |
| BR-EL-001 | 听力内容唯一知识来源仍是当前学生可见的已上传或归档英语教材章节。模型只接收选中章节正文、章节标题和教材年级；不接收广州外部教材、试题、原文或任何可复现材料。 |
| BR-EL-002 | “广州市普通小学对应年级能力”定义为“教材年级 + 2022 版英语课程标准的通用年级能力规则”，且只用于控制原创脚本的词汇、句长、题型和语速，不构成广州本地教材或试题来源。 |
| BR-EL-003 | 年级控制采用三个稳定档：1-2 年级为基础档，3-4 年级为发展档，5-6 年级为提升档。每档定义脚本长度、句子复杂度、题型与默认建议语速；默认语速依次为 `0.75x`、`1.00x`、`1.10x`。模型不得把这些规则当作可引用的外部题源。 |
| BR-EL-004 | 听力首次完整播放后，理解题解锁；同时显示默认折叠的“查看听力文本”控件。提交前只显示脚本，不显示答案、解析、评分点或对错信息。 |
| BR-EL-005 | 正式取消两次播放限制。音频可无限次播放、暂停、重新开始及切换慢速/标准/加快速度；播放次数只作学习进度记录，不作为禁播条件。 |
| BR-EL-006 | 每个听力包在创建时保存不可变的年级档、建议语速和原创内容版本。学生的慢速/标准/加快选择只改变当前播放，不重新生成脚本、题目或答案。 |
| BR-EL-007 | 默认速度和可选速度必须直接对应已生成音频的受控语速档；不得仅以按钮文案假装变速。速度变更后的 TTS 缓存不得与其他速度档混用。 |
| BR-EL-008 | 历史听力包可继续读取：没有新字段时按原有脚本与默认标准速度播放，不受两次播放上限限制；首次完整播放后同样可展开文本。 |
| BR-EL-009 | 学生提交听力题时，系统保存以题目 ID 为键的作答快照。提交后及重新进入任务时，每题连续展示题目、学生答案、参考答案、解析和评分点；不显示对错、分数或模型批改结论。首个成功提交的快照不可被后续重复请求覆盖。 |

### 年级档默认值

| 教材年级 | 能力档 | 原创脚本 | 理解题 | 默认/可选播放 |
| --- | --- | --- | --- | --- |
| 1-2 | 基础 | 45-70 英文词；熟悉主题、单句或双句轮次 | 2-3 道事实识别/图片或选项匹配 | 默认慢速 `0.75x`；可切换标准/加快 |
| 3-4 | 发展 | 70-110 英文词；短对话或短文，含一项明确关键信息 | 3 道事实理解/简单推断 | 默认标准 `1.00x`；可切换慢速/加快 |
| 5-6 | 提升 | 100-140 英文词；连贯短文或多轮对话 | 3-4 道事实理解/顺序或简单推断 | 默认加快 `1.10x`；可切换慢速/标准 |

## 4. 风险

- “广州对应年级”若被实现为抓取、引用或复述外部教材/试卷，将违反 BR-EL-001；生成日志和提示词不得保存外部文本。
- 去掉播放上限后，不能再把 `completedPlays` 当作作答门槛；仍需以首个完整播放事件作为题目和文本的解锁依据。
- 同一脚本的不同语速音频若共享缓存键，会出现按钮速度与实际音频不一致；缓存身份必须包含受控速度档。
