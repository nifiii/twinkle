# 已生成学习资料管理与英语听力历史修复：业务需求

状态：Gate 1 已确认

## 1. 背景

智慧课堂内存在历史英语听力失败任务。其原因是历史三年级英语教材的结构化 `grade` 为“小学”，或目录标题不能定位到已解析章节正文。对这类不可恢复输入展示“重新生成”会重复失败。

学习资料当前只承载家庭上传资料，缺少面向学生和家长的“已生成学习资料”管理入口，不能按学科和学习进度查找或删除系统生成的内容。

## 2. 目标

1. 修复教材元数据和章节锚点后，只有输入完整的英语听力任务才可生成。
2. 清除没有任何学习内容、作答或进度的历史失败英语听力任务。
3. 在“学习资料”下增加“已生成学习资料”页面，使当前学生可按学科、待学习和已完成筛选并删除生成资料。
4. 删除生成资料不能删除家庭上传教材、上传试卷、扫描资料、已提交作答回顾或“需巩固”错题标记。

## 3. 方案

### 3.1 术语

| 术语 | 定义 | 不包括 |
|---|---|---|
| 已生成学习资料 | 系统成功生成并有可访问主内容的学习任务及其课件、随堂测验、听力、思维训练、错题讲解或模拟考试。 | 家庭上传的教材、试卷、扫描资料。 |
| 待学习 | 已生成资料对应任务处于 `not_started` 或 `in_progress`。 | 生成失败、已删除或已完成。 |
| 已完成 | 当前学生完成对应任务的学习状态为 `completed`。 | 已生成但尚未开始的内容。 |
| 删除生成资料 | 删除任务入口及仅由该任务拥有的生成内容，使其不再出现在智慧课堂或已生成学习资料。 | 删除上传原件、作答回顾和错题标记。 |
| 历史失败任务 | 生成状态为 `failed` 或 `resource_unavailable` 且没有生成内容链接的旧任务。 | 已成功生成的听力或任何可继续学习任务。 |

### 3.2 业务规则

| ID | 规则 |
|---|---|
| BR-GLM-001 | 已生成学习资料页面仅列出当前学生资料上下文中的 `ready` 任务；上传资料不混入该页面。 |
| BR-GLM-002 | 页面必须提供学科筛选，以及“全部、待学习、已完成”进度筛选；默认显示全部学科和全部进度。 |
| BR-GLM-003 | 每项资料展示学科、资料类型、教材和章节锚点、生成时间、学习进度及继续学习入口。 |
| BR-GLM-004 | 删除必须经过明确确认，并说明“学习资料将下线，作答回顾和需巩固标记会保留”。 |
| BR-GLM-005 | 删除后，任务和其仅关联的生成内容不能从智慧课堂、已生成学习资料或旧任务地址继续读取。作答回顾必须仍可从其既有记录入口读取。 |
| BR-GLM-006 | 删除一项资料不得删除上传教材、上传试卷、扫描资料、原始文件或其他任务共用的生成内容。 |
| BR-ELR-001 | 英语听力只能使用教材结构化年级可映射到 1-6 年级能力档，且目录章节必须能定位到已解析正文。 |
| BR-ELR-002 | 生产修复先生成数据库备份和待删除清单；仅删除无内容链接、无作答、无进度的历史失败英语听力任务。 |
| BR-ELR-003 | 失败原因为教材年级、目录或正文不完整时，界面展示不可重试原因，不得提供会重复失败的“重新生成”。 |

### 3.3 用户路径

1. 学生从“学习资料”进入“已生成学习资料”。
2. 按学科和进度筛选，继续已有学习或查看资料状态。
3. 对不再需要的生成资料选择删除，阅读保留范围后确认。
4. 系统下线学习资料，保留作答回顾和需巩固标记。

家长或维护者修复历史教材时：备份当前数据，更新结构化年级，验证目录和正文锚点，审核失败任务清单后删除无内容的失败任务；学生再按需要创建新的听力。

### 3.4 非目标

- 不提供上传教材、试卷或扫描资料的删除入口。
- 不在本轮批量重新生成历史英语听力，避免同章节产生重复内容。
- 不删除已提交作答回顾或已有错题标记。
- 不把 `ownerId` 扩展为安全隔离边界。

## 4. 风险

| 风险 | 控制措施 |
|---|---|
| 删除误伤共享或其他任务内容 | 仅删除已验证为当前任务唯一拥有的生成实体；共享引用改为阻断并要求人工处理。 |
| 删除后作答回顾失效 | 删除前验证作答记录拥有题目、学生答案、参考答案和解析快照；缺少快照时阻断删除。 |
| 历史教材标签未同步到结构化字段 | 以生产 API/SQLite 的 `books.grade` 为准，标签或文件名不作为成功证据。 |
| 章节目录与正文不一致 | 在重试或新建听力前验证目录锚点；不满足时显示资料修复原因。 |

## 5. 确认记录

| 日期 | 决策 | 理由 |
|---|---|---|
| 2026-08-06 | 删除生成资料时保留作答回顾和需巩固标记。 | 学习记录属于学生历史，不应因清理学习内容而丢失。 |
| 2026-08-06 | 历史失败听力先备份、审核后删除，不批量重试。 | 失败任务没有可学习内容，且批量重试会造成重复学习资料。 |
