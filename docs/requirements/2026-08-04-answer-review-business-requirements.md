# 作答回顾与需巩固标记：业务需求（Gate 1）

## 1. 背景

当前系统会在学生提交课堂测验、作业或试卷后自动判断对错、计算分数，并对解答题调用模型批改。该行为把学习回顾误做成考试判分，且会把自动判定的题目写入课堂错题来源。

## 2. 目标

提交后立即给学生一个完整、可对照的作答回顾：每题的题目、自己的答案、参考答案与解析始终在同一题目区域。学生或家长只在主动标记“需巩固”时，才把该题作为错题处理。

## 3. 方案

### 3.1 业务规则

| ID | 规则 |
| --- | --- |
| BR-AR-001 | 课堂测验、作业与试卷的网页作答在提交后立即保存为“作答回顾”，不得进入异步或同步自动批改。 |
| BR-AR-002 | 每个已提交题目必须在同一区域连续展示题目、学生答案、参考答案、解析；未作答也必须显示。 |
| BR-AR-003 | 新旧作答回顾均不得显示对错、分数、得分率、学习建议、批改状态、复核或改判入口。 |
| BR-AR-004 | 已提交题目可由学生或家长主动标记/取消“需巩固”。被标记题目是课堂作答错题；未标记题目不是错题。 |
| BR-AR-005 | “需巩固”只改变课堂错题来源，允许被统一错题本、错题讲解与专项测验读取；课堂测验使用 `quiz_result` 来源，网页/A4 试卷使用 `paper_attempt` 来源；不得写入 `scanned_items` 或教师批注错题统计。 |
| BR-AR-006 | 历史评分数据必须删除：包括每题对错、评分量规/证据、分数、得分率、AI 学习建议、批改时间、改判和复核事件。历史题目、学生答案、参考答案、解析、作答时间和需巩固标记保留。 |
| BR-AR-007 | 上传作业/试卷中原有教师批注、红笔标记及其错题归档语义保持不变；它们不是本功能的系统批改结果。 |
| BR-AR-008 | 我的看板不再读取或显示任何基于系统评分计算的掌握率、成绩趋势或成绩卡片。 |

### 3.2 术语

| 术语 | 定义 | 不使用的旧称 |
| --- | --- | --- |
| 作答回顾 | 已提交题目的只读对照页面 | 批改结果、成绩详情 |
| 需巩固 | 学生/家长主动选择、作为后续学习输入的课堂题目状态 | 自动错题、判错 |
| 课堂作答错题 | 一条已提交且标记“需巩固”的题目 | 自动判错题 |
| 教师批注错题 | 上传资料中已有教师标记而归档的错题 | 系统批改结果 |

### 3.3 非目标

- 不判断学生答案是否正确，不为任何题型调用模型评分。
- 不修改上传资料 OCR 的教师批注读取、归档或删除规则。
- 不恢复历史分数、改判或复核能力。
- 不改变原创出题、教材、PDF 导出或作答录入能力。

## 4. 风险

- 评分数据删除不可逆，必须备份、输出清单、人工确认后才允许生产执行。
- 历史结果若没有参考答案或解析，不能伪造；应显示明确的“该历史题未保留参考答案/解析”占位状态。
- 需巩固标记是主观学习选择，不能被看板或统计解释为客观正确率。
