# 1. 背景

当前原创试卷生成只读取教材或母卷的文字摘要，无法可靠处理母卷中的听力分区、多选题和图形材料。用户已确认复用现有英语听力/TTS与OCR/视觉模型能力，并保持原创题边界。

# 2. 目标

- 使用用户已上传且可安全读取的原始 PDF 页面作为母卷视觉证据。
- 仅在视觉证据完整、题型材料可生成时创建原创试卷；材料缺失继续阻断且不保存半成品。
- 支持 `multi_choice` 多选题、听力题（有听力原文时复用现有原创脚本和TTS）及简单图形题资源。
- 保持旧纯文字母卷链路兼容，生成内容不复现母卷原题全文、原文或原图。

# 3. 方案

原始 PDF → 页面渲染 → Vision 结构化证据（分区/题号/资源/缺失项）→ 文本模型原创生成 → 原子校验 → 网页作答与 PDF 导出。

证据只保存页码、区域锚点、摘要和资源引用；原始页面不进入生成题内容。听力仅在存在完整听力原文时生成原创脚本并通过现有TTS播放；只有音频没有原文时返回明确阻断。

# 4. 风险

- Vision 模型配置缺失或页面渲染失败会阻断生成，不静默降级。
- 复杂图形题暂不支持学生自由绘图输入；简单图形使用原创 SVG/Canvas 资源。
- 生产环境模型调用、文件上传和部署不在本轮自动执行范围内。
