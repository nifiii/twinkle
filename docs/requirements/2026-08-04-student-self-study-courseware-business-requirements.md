# 学生自学课件：业务需求基线（Gate 1）

状态：已确认；2026-08-04 变更控制已纳入历史教材章节课件删除规则

## 1. 背景

当前教材章节课件只要求生成标题、正文和备注，未定义学习对象、讲解节奏、理解检查或学生可执行的学习闭环。因此内容可能采用面向教师的备课提纲或授课提示，学生独自阅读时缺少知识点解释、示例和自检路径。

## 2. 目标

将“教材章节课件”定义为小学生可独立完成的章节自学内容：学生选择已归档教材的具体章节后，得到按知识点逐步讲解、可阅读、可思考、可练习并可进入随堂测验的学习任务。

成功标准：对应年级学生不依赖教师口头补充，能够理解课件中列出的章节知识点，完成非计分自检，并进入对应的随堂测验进行学习诊断。

## 3. 方案

### 3.1 用户与流程

| 角色 | 当前流程 | 目标流程 |
| --- | --- | --- |
| 学生 | 选择教材章节，阅读可能偏教师的课件，另行进入测验。 | 选择教材章节，按“目标 → 讲解 → 示例 → 自检 → 小结”完成自学，再进入同章节随堂测验。 |
| 家长 | 只能从完成结果判断学习情况。 | 可从智慧课堂查看课件完成与测验诊断，不把课件内自检计入正式成绩。 |

```text
已上传教材章节
  -> 创建“学生自学课件”任务
  -> 学习目标与预备回忆
  -> 知识点分步讲解与示例
  -> 非计分即时自检
  -> 易错提醒与小结
  -> 同章节随堂测验
  -> 智慧课堂保存学习任务与诊断
```

### 3.2 业务规则

| ID | 规则 |
| --- | --- |
| BR-SSC-001 | 新创建的教材章节课件必须以学生自学为唯一受众，不得输出教师授课话术、教案目标、板书安排、课堂管理、家长指导语或“教师备注”。 |
| BR-SSC-002 | 课件必须严格以学生选择的、已上传或家庭共享教材的具体章节正文为依据；不使用平台内置教材或泛化课件替代。 |
| BR-SSC-003 | 每份课件必须包含：学习目标、知识点分步讲解、至少一个贴合本章节的示例或情境、非计分即时自检、易错提醒或学习策略、章节小结与进入随堂测验的行动。 |
| BR-SSC-004 | 课件以一个可学习的知识点为一个阅读步骤；每步只讲一个核心概念，使用对应年级可理解的简体中文。不得仅罗列定义、结论或知识点标题。 |
| BR-SSC-005 | 学科示例必须匹配章节：数学展示推理过程与答案核对；英语展示语境、词句理解与朗读/听辨提示；语文展示文本理解、语言积累或表达路径；科学展示观察、证据与结论的区分。 |
| BR-SSC-006 | 即时自检只用于引导学生思考和显示讲解反馈，不计入分数、排名或学习诊断；正式学习诊断仍由独立的随堂测验和既有批改流程承担。 |
| BR-SSC-007 | 课件完成后必须提供进入同一教材、同一章节范围随堂测验的明确行动；未生成测验时不得伪称学生已经掌握。 |
| BR-SSC-008 | 每次生成仍创建新的、不可覆盖的学习任务；新任务不得覆盖既有测验、作答、成绩或错题记录。 |
| BR-SSC-009 | 智慧课堂应将新课件标识为“学生自学课件”，并展示教材、章节、学习进度和进入随堂测验的关联；不暴露模型提示词或内部教师备注。 |
| BR-SSC-010 | 内容生成失败、章节正文不足或结构校验不通过时，任务必须标为失败并允许重试；不得保存成看似可学习但缺少讲解或自检的课件。 |
| BR-SSC-011 | 新版服务上线前，删除学习小助手生成的全部学习资料及关联记录，包括教材课件、错题讲解课件、随堂测验、模拟考试、作答、成绩、错题与学习任务；删除后不得保留历史阅读、任务详情入口或重定向。 |
| BR-SSC-012 | 删除前必须生成可恢复的数据库和专属文件备份及待删除清单。必须保留用户上传教材、用户上传试卷及其原始文件；上传试卷以 `scanned_items.type='exam_paper'` 识别。不得删除 `books`、非错题扫描资料或其源文件。 |

### 3.3 输入与输出

| 类别 | 内容 |
| --- | --- |
| 输入 | 当前学生、教材 ID、具体章节 ID、已解析章节正文、学科、年级。 |
| 输出 | 学生自学课件结构、非计分自检反馈、同章节随堂测验入口、智慧课堂任务索引。 |
| 约束 | 仅使用家庭归档教材；课件和测验均为原创内容；自动批改只用于学习诊断。 |

### 3.4 共享术语

| 术语 | 定义 | 不使用的含义 |
| --- | --- | --- |
| 学生自学课件 | 面向学生独立完成章节学习的结构化内容。 | 教师教案、讲课提纲、PPT 演讲备注。 |
| 即时自检 | 嵌入课件的非计分思考或小练习，立即显示讲解反馈。 | 需要提交成绩的正式测验。 |
| 随堂测验 | 与同一教材章节绑定的独立原创测验，用于学习诊断。 | 课件内的非计分自检。 |
| 学习步骤 | 围绕单一知识点的可阅读、可理解、可检查的课件单元。 | 单纯按 PDF 页或模型输出长度切分的幻灯片。 |

### 3.5 MVP 与非目标

**MVP**

- 先清空既有学习小助手派生学习数据，再创建学生自学课件。
- 四个现有学科均支持学生自学结构与学科适配示例。
- 课件内即时自检不记录分数；随堂测验复用现有诊断链路。
- 智慧课堂可识别并继续学生自学课件。

**非目标**

- 不删除用户上传教材、用户上传试卷、非错题扫描资料或对应原始文件。
- 不替代教师备课、在线授课、实时答疑或家长辅导。
- 不增加教材以外的知识范围、正式成绩、排名或学校作业提交。
- 不在本阶段创建新的学科题库或修改既有随堂测验评分规则。

### 3.6 边界与异常

- 学生选择多个章节时，课件必须按章节和知识点分段，不能混合成无来源的概览。
- 章节正文无法定位、过短或解析失败时，拒绝生成并说明需要重新解析教材。
- 模型遗漏任一必需学习步骤时，视为生成失败，不展示半成品。
- 学生可以跳过课件内的即时自检，但进入随堂测验前应得到“建议先完成自检”的提示；是否强制完成由产品决策确定。

## 4. 风险

| 风险 | 原因 | 控制方向 |
| --- | --- | --- |
| 只替换提示词，内容仍不稳定 | 当前没有可机读的学生课件结构和质量校验。 | 固定输出契约，并在保存前校验学习步骤与禁用教师话术。 |
| 删除范围误伤用户上传资料 | 上传试卷、错题与学习助手数据共用扫描与文件存储。 | 迁移采用源资料白名单；只删除 `wrong_problem` 扫描项及经引用验证的专属文件；其他扫描项和 `books` 绝不在删除 SQL 中出现。 |
| 课件自检与随堂测验混淆 | 两者都可能出现题目。 | 明确自检非计分、随堂测验负责诊断，并以不同 UI 与数据字段表达。 |
| 章节正文质量不足 | 历史教材可能缺少 Markdown 或目录锚点。 | 复用教材有效性校验；失败时回到教材解析，不生成泛化内容。 |

## 5. 已确认决策

| ID | 决策 | 建议默认值 | 原因 |
| --- | --- | --- | --- |
| D-SSC-001 | 既有学习小助手资料如何处理？ | 删除全部派生学习数据及关联记录；不保留历史访问入口。 | 用户已确认。上传教材、上传试卷及其原始文件必须保留；备份、清单和关联验证不可跳过。 |
| D-SSC-002 | 即时自检是否必须完成才可进入随堂测验？ | 不强制；提示建议完成。 | 自学应允许学生按需回看，正式诊断由独立测验负责。 |
| D-SSC-003 | 每份课件的建议学习长度。 | 6 至 10 个学习步骤、10 至 20 分钟。 | 适合小学阶段注意力与移动端连续阅读。 |
