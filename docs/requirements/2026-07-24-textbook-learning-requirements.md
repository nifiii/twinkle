# 教材驱动学习与测评：业务需求与术语（Gate 1）

状态：已确认

## 1. 背景

现有系统已经有教材、章节课件、章节测验、错题与测验记录，但不能按教材章节提供多学科资源、考试卷、复习大纲和可解释的过程性阅卷。

## 2. 目标

让学生从一本已归档教材的某个章节，在三次点击内开始学习、练习或测试；所有资源和测评必须可追溯到该教材范围，自动成绩仅用于学习诊断。

## 3. 方案

### 3.1 统一术语

| 术语 | 定义 | 禁止混用 |
| --- | --- | --- |
| 教材锚点 | 家庭共享或学生已归档的 `bookId + 学科 + 年级 + 章节目录`。新上传教材默认使用 `ownerId=shared`。 | 不等于平台内置教材。 |
| 学习包 | 针对一个教材锚点生成的资源集合：视频链接、听力、复习大纲或练习。 | 不等于课件。 |
| 命题蓝图 | 考试范围、题型、分值、难度和风格约束。 | 不等于试卷正文。 |
| 原创试卷 | 按蓝图生成的全新题目，不复现样本真题全文。 | 不标注“真题”。 |
| 风格样本 | 公开可核验广州试卷或学生上传奥数资料提取出的题型、难度和知识点摘要。 | 不作为公开题库。 |
| 评分量规 | 每道主观题的得分点、过程要求、结果要求和分值。 | 不等于参考答案。 |
| 复核 | 学生或家长对一题自动结果提出异议，或直接手动改判。 | 不等于重新生成试题。 |

### 3.2 业务规则

| ID | 规则 |
| --- | --- |
| BR-001 | 内容范围只能来自家庭共享或当前学生已归档的教材、教辅、奥数资料和试卷资料；新上传教材默认归档到家庭共享资料库（`ownerId=shared`），所有现有学生均可选择。教材年级、学科或目录缺失时，先要求用户补全，禁止声明章节覆盖。 |
| BR-002 | 英语听力是“AI 原创练习”：按教材章节生成脚本、题目、答案、评分点和 TTS 音频；不能标为教材原声、官方听力或真题。 |
| BR-003 | 数学思维覆盖数感、数形结合、方程等从教材或奥数资料提取到的知识点；奥数只覆盖该资料标注的年级。 |
| BR-004 | 英语、数学和科学视频只返回公开第三方链接及资源元数据；仅返回 `reviewedAt` 非空且 `linkHealthStatus=healthy` 的资源。不下载、转存、代理播放或向第三方传递学生个人信息。 |
| BR-005 | 单元、期中、期末与复习大纲均由命题蓝图驱动；生成前必须显示并允许选择难度，默认采用现有 2 星。 |
| BR-006 | 试卷必须覆盖已选教材范围；题型、题数、分值和总时长可审查，网页与 A4 版使用同一份结构化试卷数据。 |
| BR-007 | 公开广州试卷和上传奥数真题仅可生成风格摘要；保存来源 URL、获取日期、适用年级/学科和人工审核状态，不保存或返回原题全文。 |
| BR-008 | 所有生成题目必须标为“原创练习/原创试卷”；风格样本不可用时，继续生成教材基础题，但不展示“广州风格”或“希望杯风格”标签。 |
| BR-009 | 客观题采用规范化答案和备选答案集合判分；主观题按评分量规分别评估知识点覆盖、推理过程、结果和表达，不因同义表述或等价步骤机械扣分。 |
| BR-010 | 自动分数仅为学习诊断。结果页必须可展示评分证据和扣分原因，允许逐题申请复核、直接改判，并保留原判与改判审计记录。 |
| BR-011 | 首期为单设备本地资料模式：前端以用户选择的 `ownerId` 作为教材、学习记录和作答的筛选上下文；该字段不是认证或服务端安全隔离。外链资源、日志和错误信息不得暴露供应商密钥、原始作答或不必要的学生身份信息。 |

### 3.3 输入、输出与异常

| 场景 | 必需输入 | 输出 | 异常处理 |
| --- | --- | --- | --- |
| 英语听力 | 英语教材章节、难度 | 音频、题目、答案、评分点 | 无正文或英语章节：阻止生成并引导修正教材。 |
| 数学思维/科学视频 | 对应教材章节、知识点 | 外链、标题、来源、时长、适龄标签 | 来源不可用：不展示链接，保留“暂无可核验资源”。 |
| 奥数练习 | 标注年级的奥数资料、章节或标签 | 原创练习与解析 | 年级缺失：要求补全资料元数据。 |
| 试卷/大纲 | 试卷类型、范围、难度、风格开关 | 蓝图、网页试卷、A4 试卷/答案卷 | 样本未审核：降级为教材原创试卷。 |
| 主观题批改 | 作答、评分量规、题目 | 得分、评分点、证据、建议、置信度 | 低置信度：标记“建议复核”，不输出确定性评语。 |

### 3.4 成功指标

- `>= 95%` 已补全元数据的教材可成功创建学习包或命题蓝图。
- 每份试卷 100% 可列出范围、题型、分值、难度和生成版本。
- 主观题结果 100% 有评分量规与证据；低置信度题目不计入“已掌握”。
- 外链可用性每日检查，失效资源不展示为可学习内容。

## 4. 风险

公开搜索结果不能等同于授权或官方来源。2026-07-24 的快速核验未确认可自动接入的广州市教育部门试卷语料库，因此首期只能支持人工审核后录入的风格摘要，禁止自动抓取和全量保存网页试卷。

首期没有认证、会话或家庭授权能力，`ownerId` 可由客户端改变，不能作为跨学生数据隔离承诺。新学习能力只能部署在受信任的单设备本地环境；接入公网、多用户设备或家庭共享前，必须先补充身份认证与服务端授权设计。

## 5. 回滚

按能力开关关闭听力、视频、风格命题或 AI 阅卷，保留原有章节测验、TTS、错题和人工二次改判。所有新增记录使用独立版本字段，不修改历史 `classroom_items` 和 `quiz_results` 语义。

## 6. FAQ

### 豆包能否按教材生成英语听力题？

可以。模型先产出原创脚本、题目和评分量规，再调用现有 TTS；产物必须明确为 AI 原创练习。

### 为什么不能直接显示广州真题或希望杯原题？

公开可访问不自动获得再分发或二次使用授权。系统只保留审核后的风格摘要，输出原创题。
