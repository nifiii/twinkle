# 学习小助手重构：业务需求基线（Gate 1）

状态：已确认（Gate 0-5）

## 1. 背景

现有“学习中心”已能从教材章节创建学习包与原创试卷，但“学习小助手”仍藏在学习资料内部，错题讲解、课件、测验和课堂内容分散。学生需要从一个独立入口快速开始学习，并能在智慧课堂继续完成和回看每次生成的内容。

## 2. 目标

1. 导航中以“学习小助手”替换“学习中心”，并固定排列为“我的看板、学习资料、学习小助手、智慧课堂”。
2. 将教材章节型学习与错题驱动型学习清晰分开，学生不必理解内部数据来源即可开始。
3. 每次生成均形成不可覆盖的学习任务，并在智慧课堂统一聚合。

## 3. 业务规则

| ID | 规则 |
| --- | --- |
| BR-001 | 全局导航固定为“我的看板、学习资料、学习小助手、智慧课堂”；学习小助手与学习资料、智慧课堂平级，且导航和任何页面标题不得保留“学习中心”。 |
| BR-002 | 移除学习中心后，不保留已生成内容的 `#learn/*` 历史访问地址或兼容重定向。 |
| BR-003 | 所有学科均提供“错题讲解与错题测验”。它从错题本和智慧课堂历史作答中读取错题，不强制关联教材或章节。 |
| BR-004 | 系统自动识别错题学科；学生可切换学科、排除误识别错题，并选择一至多题后生成学习任务。 |
| BR-005 | 错题学习任务包含逐题讲解、错误归因、正确思路/关键步骤，以及只覆盖所选错题知识点的原创针对性测验。 |
| BR-006 | 课件生成与随堂测验必须绑定已上传或家庭共享教材的具体章节；没有符合条件的教材或章节时不可生成。 |
| BR-007 | 英语、数学、语文、科学的视频学习必须绑定已上传或家庭共享教材的具体章节。 |
| BR-008 | 视频仅能嵌入第三方公开视频。审核条件包括公开可访问、适龄、链接健康且技术上允许嵌入；不代理、下载、转码、托管或绕过第三方限制。无可用资源时不创建任务。 |
| BR-009 | 英语可生成教材章节绑定的听力测试、视频学习和模拟考试；听力题为原创内容。 |
| BR-010 | 数学可生成教材章节绑定的视频学习、思维训练和模拟考试；只有存在学生上传且标注匹配年级的奥数资料时，才显示奥数模拟考试。 |
| BR-011 | 语文和科学可生成教材章节绑定的视频学习与模拟考试。 |
| BR-012 | 英语、语文、科学模拟考试按教材范围选择单元/期中/期末和基础/标准/挑战难度；数学也支持此教材型考试，并按 BR-010 额外支持奥数模拟考试。 |
| BR-013 | 平台仅生成原创题。近一年广州公开试卷和学生上传奥数真题仅可提取题型、难度与知识点风格，不保存或复现原题全文。 |
| BR-014 | 每次生成创建一条新的学习任务，不覆盖或修改既有任务。试卷继续遵循版本递增和旧卷不可变规则。 |
| BR-015 | 智慧课堂以统一学习任务索引聚合课件、随堂测验、错题讲解与测验、听力、视频、思维训练和模拟考试；原有实体、详情、作答和版本数据不复制。 |
| BR-016 | 自动批改分数仅用于学习诊断；学生或家长可逐题申请复核或手动改判。 |
| BR-017 | `ownerId` 标识当前家庭内选择的学生档案，并决定教材、错题、任务和作答的资料视图及记录归属；首期不提供登录、角色或家庭成员授权管理。 |
| BR-018 | 新上传或归档教材默认属于现有全部学生可见的家庭共享资料；学生也只可从当前可见教材范围选择章节。 |
| BR-019 | 英语听力测试以所选教材章节正文生成原创脚本和题目，沿用两次完整播放限制；完成播放前不得提交理解题。 |
| BR-020 | 模拟考试继续支持试卷式网页作答、学习诊断、逐题复核或改判，以及可打印/下载的 A4 试卷与答案卷。 |

## 4. 当前与目标流程

```text
当前：学习资料 > 内嵌小助手 / 学习中心 > 学习包或试卷 / 智慧课堂
目标：学习资料 / 学习小助手 > 生成新学习任务 > 智慧课堂 > 原有详情与作答实体
```

学习小助手的两条入口流：

1. 错题流：选择自动归类的学科和错题，可校正选择，生成讲解与针对性原创测验。
2. 教材流：选择已归档教材和具体章节，显示该学科允许的课件、随堂测验、听力、视频、思维训练和模拟考试能力。

## 5. 共享术语

| 术语 | 定义 | 不使用的含义 |
| --- | --- | --- |
| 学习小助手 | 学生选择错题或教材章节并发起学习内容生成的独立页面。 | 学习资料的内部子标签。 |
| 学习任务 | 指向一次生成产物或一次合格视频学习的统一索引记录，含类型、来源锚点、状态和创建时间。 | 复制课件、试卷或学习包实体。 |
| 教材流 | 以学生可见的已上传教材及具体章节为输入的生成流程。 | 平台内置教材或无章节的泛化生成。 |
| 错题流 | 以错题本和课堂历史作答中的错题为输入的独立流程。 | 必须关联教材章节的功能。 |
| 可嵌入视频 | 审核通过、健康、适龄且第三方技术上允许在站内嵌入的公开视频。 | 可搜索、下载、代理或站内托管的视频。 |
| 智慧课堂 | 已生成或已创建的学习任务的统一聚合、继续学习和历史查看页面。 | 新的内容复制仓库。 |

## 6. 风险

- BR-002 使旧 `#learn/*` 书签和历史链接失效。发布时须用新入口承接，且不能承诺旧链接可恢复。
- 第三方视频的嵌入权限会变化；健康检查与嵌入许可均必须是展示前置条件。
- 统一任务索引若和原实体写入不同步，会出现“已生成但课堂不可见”或死链接；该一致性须在技术设计和验收中验证。
- 当前范围只覆盖协作式家庭使用；跨家庭共享、公开多用户访问或角色权限管理必须作为独立需求设计。

## 7. 回滚

在发布阶段以功能开关控制新导航和学习任务聚合。关闭后仅恢复旧的可用页面入口；按 BR-002 不承诺恢复旧 `#learn/*` URL。已经存在的原实体数据不得删除或覆盖。

## 8. FAQ

### 为什么错题流不要求教材章节？

错题的学习价值来自学生实际错误与知识点归因。强行绑定教材章节会在扫描错题、跨册练习或课堂历史作答时阻断使用。

### 为什么视频没有资源时不创建任务？

没有可嵌入且健康的公开资源时，创建任务只会产生无法完成的记录；空状态更诚实且可复核。
