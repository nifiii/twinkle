# 实现“拍题”流程与详情页图片的“二级放大”功能

## 1. 核心交互设计

* **状态循环**：点击图片时，缩放级别按 `1x (原始)` -> `1.5x (一级放大)` -> `2.0x (二级放大)` -> `1x (重置)` 循环切换。

* **平滑过渡**：使用 CSS `transition` 或 `framer-motion` 实现缩放时的动画效果，确保视觉流畅。

* **滚动适配**：在大倍率缩放时，确保容器支持溢出滚动，以便用户查看图片边角细节。

## 3. 验证方案

1. **校验流程验证**：上传图片后进入校对界面，连续点击图片，验证是否能实现两次梯级放大，并能回到原始大小。
2. **历史档案验证**：进入“历史档案”，打开一份已保存的试卷，切换到“原始试卷”标签，验证同样的二级放大功能是否生效。
3. **边界检查**：验证在二级放大（2.5x）时，是否可以通过鼠标或触摸滚动查看图片的全部内容。
