# 优化拍题图片交互：拖拽查看与多页切换

## 1. 图片拖拽功能实现 (取代滚动)
*   **交互逻辑**：固定图片展示框的大小。当图片处于放大状态（1.5x 或 2.5x）时，用户可以直接通过鼠标/手指拖拽图片来查看不同区域，而不是使用滚动条。
*   **技术方案**：
    *   利用 `framer-motion` 的 `drag` 属性。
    *   设置 `dragConstraints` 确保图片在拖拽时边缘不会过度超出视口，保证查阅核对的稳定性。
    *   保持容器 `overflow-hidden`，确保 UI 整洁。

## 2. 多页图片切换功能
*   **交互逻辑**：当一次上传多张图片（连拍/多选）时，在图片展示框上方增加一个切换工具栏。
*   **功能点**：
    *   **CaptureModule (校对页)**：显示“第 1/N 页”及左右切换箭头，或者数字按钮，点击后立即切换当前预览图。
    *   **KnowledgeHub (详情页)**：同步支持多图切换，确保用户可以查阅整份试卷的所有原始页面。
*   **状态同步**：切换图片时不重置当前的缩放倍率，方便用户在相同位置对比不同页面的细节。

## 3. 技术实施步骤

### 第一步：更新 CaptureModule.tsx
*   在 `reviewItem` 展示区域增加 `currentImageIndex` 状态。
*   实现拖拽容器与 `motion.img` 的拖拽绑定。
*   在图片上方添加 `Pagination` 组件样式，支持多图跳转。

### 第二步：更新 KnowledgeHub.tsx
*   在 `PaperDetailModal` 中增加多图检测逻辑（解析 `allImagesJson`）。
*   同步实现图片拖拽查看功能。
*   增加顶部图片切换按钮。

## 4. 验证方案
1.  **多图验证**：上传 3 张图片，验证上方是否出现切换按钮，点击是否能准确切换。
2.  **拖拽验证**：放大图片后，验证是否能顺畅拖拽，且不会出现滚动条影响核对。
3.  **详情验证**：查看已保存的多页试卷，验证详情弹窗内的切换与拖拽功能。
