# 在“拍题-人工校验”后实现错题自动剥离与归集方案

## 1. 业务流程重塑
根据您的要求，我们将拍题流程细化为：
`拍题上传` -> `AI识别` -> **`人工校验（当前步骤）`** -> **`点击保存（触发后续）`** -> **`[新增] 自动剥离错题`** -> **`[新增] 错题数据库归档`** -> `前端分类显示`。

## 2. 技术实施方案

### A. 错题自动剥离逻辑 (后端 fileStorage.ts)
*   **功能增强**：在主试卷保存函数 `saveObsidianMarkdown` 中，增加一个子流程：
    1.  遍历经过人工校对后的题目列表。
    2.  识别标记为“错误”或“已订正”的题目。
    3.  为每道错题生成独立的 ID。
    4.  为每道错题生成一份专属的 Markdown 复盘文档，保存至 `/opt/hl-os/data/obsidian/Wrong_Problems` 目录。
    5.  返回所有新生成的错题元数据列表。

### B. 错题持久化归集 (后端 saveScannedItem.ts)
*   **接口升级**：更新 `save-scanned-item` 路由。在主试卷入库后，立即启动错题归集：
    1.  接收剥离出的错题元数据。
    2.  循环调用数据库索引更新函数，将每道错题作为独立条目存入 SQLite 的 `scanned_items` 表。
    3.  确保错题条目的 `type` 字段准确标记为 `wrong_problem`，以便前端筛选。

### C. 前端分类显示能力
*   **数据自动加载**：由于错题已进入数据库索引，前端 `fetchScannedItems` 接口在下次加载或切换至“错题”分类时，会自动检索出这些原子化的错题条目。
*   **复盘体验**：在“错题”分类下，用户可以直接点击这些剥离出来的单题进行查看和复盘，无需在整卷试卷中寻找。
