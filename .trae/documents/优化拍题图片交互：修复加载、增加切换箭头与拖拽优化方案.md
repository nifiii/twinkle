# 优化拍题图片交互：修复加载、增加右切换箭头与拖拽优化

## 1. 修复图片加载与显示逻辑
*   **路径补全**：检查并确保图片 `src` 始终包含正确的 Base URL（针对后端存储的相对路径），防止在刷新或查看历史档案时出现空白。
*   **样式调整**：优化 `motion.img` 的尺寸控制逻辑。在放大（1.5x/2.5x）状态下，解除 `maxWidth/maxHeight` 的百分比限制，改为由 `scale` 驱动，并配合容器的 `overflow-hidden` 确保拖拽体验。

## 2. 增加右侧循环切换箭头 (多页支持)
*   **交互增强**：在图片展示框的右侧（以及左侧）增加绝对定位的浮动箭头按钮。
*   **逻辑实现**：
    *   点击右侧箭头：`currentImageIndex = (currentImageIndex + 1) % totalPages`。
    *   点击左侧箭头：`currentImageIndex = (currentImageIndex - 1 + totalPages) % totalPages`。
*   **视觉反馈**：按钮仅在多于 1 页时显示，且增加悬停高亮效果。

## 3. 优化拖拽查阅体验
*   **动态约束**：优化 `framer-motion` 的拖拽约束。在放大状态下，确保图片可以平滑地被拖拽至边缘，而不会被强行弹回中心，方便用户核对细小的文字内容。
*   **固定视口**：维持展示框大小固定，确保 UI 整体结构的稳定性，不随图片缩放而改变页面布局。
