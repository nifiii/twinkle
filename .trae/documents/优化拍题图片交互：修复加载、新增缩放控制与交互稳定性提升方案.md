# 拍题图片交互精准优化：按钮控制与界面精简

## 1. 彻底解决缩放与拖拽冲突
*   **移除点击缩放**：完全删除点击图片区域触发放大的逻辑。
*   **新增缩放工具栏**：在图片展示框的右下角添加固定的“放大”(+) 和 “缩小”(-) 按钮。
*   **交互逻辑**：
    *   点击 `+`：倍率按 `1.0x -> 1.5x -> 2.5x` 步进。
    *   点击 `-`：倍率按 `2.5x -> 1.5x -> 1.0x` 步退。
    *   这确保了用户在拖拽图片查看细节时，不会因误触而导致倍率跳变。

## 2. 界面视觉精简
*   **移除数字按钮**：删除图片展示框上方（或下方）的所有“页 1”、“页 2”等数字切换按钮。
*   **强化箭头切换**：仅保留左右两侧的 `ChevronLeft` / `ChevronRight` 循环切换箭头，保持视觉上的极简与专业。

## 3. 修复加载与稳定性
*   **路径修复**：优化图片路径处理函数，解决特定浏览器下 `/uploads` 路径 404 的问题。
*   **拖拽不回弹**：设置 `dragElastic={0}`，确保图片拖拽到边缘后稳定停靠，不产生回弹效果，方便精准对齐核对。
